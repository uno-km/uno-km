소개 및 아키텍처 개요

모바일 및 에지 실리콘을 위한 통합 Vulkan 컴퓨트 가속 런타임 & 하드웨어 추상화 계층(HAL)

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install ameva-runtime

# Node.js 공식 패키지 매니저
npm install @ameva/runtime

기술적 당면 과제

모바일 안드로이드 환경에서 GPU 가속 AI를 구동할 때 퀄컴 Adreno의 JIT 컴파일러 결함(VK_ERROR_UNKNOWN -13), ARM Mali의 정수 나눗셈 보폭 0 절삭 무한 루프, Bionic과 Mesa 간 로더 충돌이 심각한 장벽이었습니다.

아키텍처 혁신 및 기술 돌파구

단일 무하드코딩 C++20 Vulkan 하드웨어 추상화 계층(HAL)을 통해 6대 멀티모달(LLM, STT, TTS, Vision, Diffusion, Train) 파이프라인을 하드웨어 결함 없이 제로카피로 고속 가속합니다.

핵심 가치 제안 (Why It Matters)

복잡한 그래픽스 드라이버와 셰이더 컴파일 지옥을 단 한 줄로 해결. 스펙 다른 어떤 스마트폰이라도 잠들어 있던 그래픽 카드의 잠재력을 100% 깨워 인공지능을 가속합니다.

주요 기능 및 하드웨어 강화

단일 무하드코딩 Vulkan HAL 계층

모바일 안드로이드 Bionic /system/lib64/libvulkan.so와 Mesa 드라이버를 단일 인터페이스로 추상화합니다.

6대 모달리티 완벽 가속

LLM(1.58비트), STT(음성), TTS(오디오), Vision(영상), Diffusion(이미지), Train(훈련) 전체를 통합 지원합니다.

하드웨어 버그 자동 격리 및 치유

Adreno 830 JIT 레지스터 버그와 Mali-G68 정수 절삭 버그를 자동 탐지하여 최적 커널로 우회합니다.

제로 묵음 실패(Zero Silent Fallback) 원칙

하드웨어 가속 결함 발생 시 조용히 CPU로 숨기지 않고 명확한 원인 진단과 복원 경로를 제시합니다.

영구 VRAM 상주 및 공유 메모리 링 버퍼

프로세스 간 데이터 복사 오버헤드를 0으로 줄이는 제로카피 IPC 파이프라인을 기본 제공합니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
Ternary 1.58-Bit GEMV Shader Vulkan 1.3 컴퓨트 셰이더 기반 3진 행렬-벡터 곱셈 프로덕션 안정
Medium MatMul Shader (_m) 워크그룹 크기 128 기반 ARM Mali 하드웨어 결함 완전 격리 프로덕션 안정
RoPE & Attention SPIR-V 하드웨어 가속 회전 위치 임베딩 및 어텐션 디코딩 프로덕션 안정
Lockless Ring Buffer HAL POSIX shm_open 기반 제로카피 오디오 및 텐서 파이프 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from ameva_runtime import RuntimeManager, DeviceType

# 1. 단말기 하드웨어 토폴로지 자동 감지 및 런타임 초기화
rt = RuntimeManager()
device = rt.select_best_device(preferred=DeviceType.VULKAN)
print(f"[AMEVA-Runtime] 활성화된 디바이스: {device.name} (Vulkan {device.vulkan_version})")

# 2. 제로카피 텐서 버퍼 할당 및 연산 디스패치
buf_a = device.allocate_buffer(shape=(1024, 1024), dtype="float16")
buf_b = device.allocate_buffer(shape=(1024, 1024), dtype="float16")
pipeline = device.create_pipeline("matmul_fp16_medium")
result = pipeline.dispatch(buf_a, buf_b)
print(f"[AMEVA-Runtime] GPU 연산 완료 지연시간: {result.latency_ms:.2f} ms")

Node.js (npm) 사용 예제

const { RuntimeManager, DeviceType } = require('@ameva/runtime');

async function main() {
  const rt = new RuntimeManager();
  const device = await rt.selectBestDevice({ preferred: DeviceType.VULKAN });
  console.log(`[AMEVA-Runtime] 선택된 하드웨어: ${device.name}`);
  const pipeline = await device.createPipeline('matmul_fp16_medium');
  const res = await pipeline.dispatch();
  console.log(`[AMEVA-Runtime] 연산 소요시간: ${res.latencyMs.toFixed(2)} ms`);
}

main();
