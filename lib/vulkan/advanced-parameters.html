고급 파라미터 제어 및 하드웨어 튜닝

모바일 실리콘 셰이더 커널 파라미터, 쿼크 격벽 및 VRAM 오프로드 제어 (AMEVA-Runtime)

Release: v2.7.7
핵심 가치 제안 (Why It Matters)

Qualcomm Adreno 및 ARM Mali 드라이버의 특이 거동(Quirks)과 컴파일러 결함을 물리적으로 우회하고, 6대 모달리티 파이프라인에서 최대 연산 처리량을 확보하기 위한 핵심 설정 규격입니다.

1. 모바일 GPU 하드웨어 쿼크 및 파이프라인 파라미터

파라미터명 기본값 / 범위 하드웨어 트레이드오프 및 엔지니어링 동작 상세
enforce_medium_matmul true (bool) ARM Mali-G68/G78(서브그룹 크기 16)에서 GLSL 정수 절삭(loadstride_b = 16 * 1 / 32 = 0)으로 인한 무한 루프를 방지하기 위해 워크그룹 크기 128인 미디엄 커널(_m, loadstride_b = 4 > 0)을 강제합니다.
mul_mat_vec_max_cols 2 (1 ~ 8) Snapdragon 8 Elite (Adreno 830) JIT 컴파일러가 특수화 상수 NUM_COLS >= 3에서 레지스터 할당 실패(VK_ERROR_UNKNOWN -13)를 일으키는 결함을 방어하기 위해 열 수를 2로 제한합니다.
flash_attention 1 (auto: 0 for Adreno 600) 스냅드래곤 865 등 구형 Adreno 600 계열 감지 시 -fa 0을 자동 주입하여 셰이더 JIT 크래시를 방지하고, Adreno 830 및 Mali GPU는 초고속 Flash Attention을 활성화합니다.
requested_ngl 999 (0 ~ 999) 모바일 GPU VRAM에 오프로드할 신경망 레이어 개수. 999 설정 시 25/25 레이어 전체를 GPU에 적재하여 CPU 컨텍스트 스위칭 지연을 제거합니다.
bionic_direct_link true (bool) Termux $PREFIX/lib/libvulkan.so의 Mesa llvmpipe CPU 에뮬레이터 함정을 우회하고, Android Bionic /system/lib64/libvulkan.so를 직접 바인딩합니다.
modality_isolation true (bool) Whisper.cpp와 LLaMA.cpp 간 공유 라이브러리(libggml-vulkan.so) 심볼 충돌을 방지하기 위해 1:1 전용 환경변수 격리 맵을 강제 적용합니다.

2. 오디오 및 비전 버퍼 타일링 제어 파라미터

파라미터명 권장 설정값 물리적 시스템 거동 분석
tts_temporal_tiling chunk_size <= 819 MeloTTS / Piper HiFi-GAN 보코더 52.4MB 버퍼 오버플로우로 인한 모바일 GPU TDR 리셋을 방어하기 위해 시간축 청크 슬라이싱을 수행합니다.
diffusion_fa true Z-Image Turbo 6.0B DiT 및 SDXS 이미지 생성 시 VRAM 피크 점유율을 1.07GB에서 수 메가바이트 수준으로 압축하는 온디바이스 플래시 어텐션 플래그.
stt_beam_size 1 (Greedy Decoding) Whisper 음성인식 추론 시 불필요한 빔 탐색 메모리 확장을 차단하고 최소 지연시간(0.07x RTF)을 유지합니다.

3. 런타임 구성 템플릿 (Python)

import ameva_runtime as ameva

# 하드웨어 자동 감지 및 최적 쿼크 주입
config = ameva.EngineConfig(
    requested_ngl=999,
    enforce_medium_matmul=True,
    mul_mat_vec_max_cols=2,
    bionic_direct_link=True
)

engine = ameva.create_engine("llm", config=config)
print(f"[AMEVA-Runtime] 가속 파이프라인 준비 완료 (백엔드: {engine.backend})")
