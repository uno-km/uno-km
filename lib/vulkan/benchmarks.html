4. Silicon & Driver Defect Resolution (Ground Truth)

  • ARM Mali-G68 Valhall Integer Truncation Infinite Loop Elimination: loadstride_b = gl_WorkGroupSize.x * LOAD_VEC_B / BK = 16 * 1 / 32 = 0 정수 나눗셈 절삭 버그로 인한 무한 루프(GPU Hang / TDR Reset)를 감지하고, Medium MatMul(_m, 작업그룹 크기 128, loadstride_b = 4)을 강제 적용하여 25/25 전 레이어 오프로딩을 안정화하였습니다.
  • Qualcomm Adreno 830 JIT 컴파일러 레지스터 할당 버그 격리: Snapdragon 8 Elite 환경에서 Specialization Constant NUM_COLS >= 3 시 발생하는 VK_ERROR_UNKNOWN (-13) 컴파일 결함을 분석하고, mul_mat_vec_max_cols = 2 경계를 강제하여 음성 입력 시 4,401ms 안정 구동을 달성하였습니다.
