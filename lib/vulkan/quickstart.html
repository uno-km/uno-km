퀵스타트 및 실행 레시피

Python, TypeScript 및 CLI 온디바이스 하드웨어 가속 표준 코드 (AMEVA-Runtime)

Release: v2.7.7
핵심 가치 제안 (Why It Matters)

기기 토폴로지와 칩셋 특성을 런타임이 자동 감지하여, 단 3줄의 코드로 하드웨어 풀 가속(Vulkan GPU / NEON CPU) AI 파이프라인을 기동합니다.

1. Python SDK 최소 실행 레시피

import ameva_runtime as ameva
from ameva_runtime import vulkan

# 1. 단말기 실리콘 토폴로지 자동 감지
profile = ameva.detect_hardware()
print(f"[AMEVA-Runtime] 감지된 SoC: {profile.soc_name} | GPU: {profile.gpu_vendor}")

# 2. 온디바이스 LLM 추론 즉시 실행 (최적 가속 백엔드 자동 라우팅)
result = ameva.run(
    model="qwen2.5-0.5b",
    prompt="스마트폰 온디바이스 AI의 장점은:",
    max_tokens=64
)
print(f"생성 텍스트: {result.text}")
print(f"사용 백엔드: {result.backend_used} ({result.tokens_per_second:.2f} t/s)")

# 3. 12단계 하드웨어 무결성 자가 진단
doc = vulkan.Doctor()
report = doc.run_self_test(verbose=False)
print(f"진단 결과: {report.passed_stages}/{report.total_stages} 단계 통과")

2. TypeScript / Node.js 실행 레시피

import { Doctor, createContext } from '@ameva/runtime';

// 1. 하드웨어 진단기 실행
const doc = new Doctor();
const report = await doc.runSelfTest();
console.log(`Vulkan GPU Target: ${report.deviceName}`);

// 2. 가속 컨텍스트 초기화
const ctx = await createContext({ device: 'auto' });
console.log(`초기화 완료 디바이스: ${ctx.deviceName}`);

3. CLI 1줄 진단 및 상태 점검

# 시스템 진단 및 Vulkan 드라이버 무결성 확인
ameva doctor

# 사용 가능한 모델 및 가속 엔진 목록 조회
ameva list
