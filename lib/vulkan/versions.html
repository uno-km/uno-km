v1.2.1 - Hardened Fail-Fast & Complete 12-Stage Diagnostic Suite

Production Release (Latest) 2026-09-02
  • Real GPU Pipeline Verification: Integrated C ABI FFI SGEMM kernel dispatch and numeric checksum ($c[0,0]=32.0$) across Doctor stages V7~V11.
  • RAII Lifecycle Adapter Cleanup: Automated unbind_all() across 6 modality adapters on context exit preventing resource and handle leaks.
  • Exynos 2100 RTLD_LAZY Isolation: Resolved Bionic GLESv3 symbol linking failure on Samsung One UI devices.
  • Strict Fail-Fast Exception Architecture: Replaced silent -1 return codes with explicit AmevaVulkanError exceptions preserving stack traces.
  • Zero-Drift Hardware Profile Packaging: Registered validated-vulkan-profiles.json in package-data with bidirectional fuzzy matching.

v1.2.1 - Galaxy A35 Validation & CTypes Pointer Patch

Maintenance Release 2026-09-01
  • Real-Device Galaxy A35 Validation: Certified 12-stage hardware diagnostic hierarchy and Vulkan 1.4 API negotiation on Samsung Galaxy A35 5G (Exynos 1380, ARM Mali-G68 GPU).
