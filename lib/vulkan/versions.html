v2.6.1 - Native Vulkan Hardware Pipeline, Bionic Direct Binding & Anti-Pattern Elimination (TTS Modality)

Major Production Release (Latest) 2026-09-15
  • Bionic Direct Vulkan Linking: Eliminates Termux Mesa llvmpipe CPU software emulator trap by dynamically binding /system/lib64/libvulkan.so directly, unleashing native Adreno and Mali hardware compute pipelines.
  • HiFi-GAN 32MB Memory Ceiling & Temporal Tiling: Overcomes mobile GPU 32MB maxBufferSize allocation limit via temporal window slicing (T_chunk <= 819), preventing VK_ERROR_OUT_OF_DEVICE_MEMORY and driver TDR resets.
  • Strict Zero-Silent-Fallback & Fail-Fast Enforcement: Completely excised disguised CPU fallback heuristics and silent exception swallowing; raises explicit RuntimeError with device telemetry on driver or memory failures.
  • Real-Device Fleet Benchmarks: Ground-truth validated across Galaxy S22 (RTF 0.88x), S21 (RTF 0.18x), S20 (RTF 0.24x), and S25 (RTF 0.12x).
  • Textbook Major Expansion: Added Sections 4.6 to 4.13 (1,200+ lines) to VULKAN_ON_DEVICE_AI_ENGINEERING_TEXTBOOK.md covering anti-pattern forensics, Roofline models, and heterogenous compute trade-offs.

v2.5.0 - Native BitNet 1.58-bit Vulkan Compute Acceleration, Permanent VRAM Residency & Zero-Copy Pipeline

Production Release 2026-09-07
  • Native BitNet 1.58-bit Vulkan Compute Engine (src/core/vulkan_bitnet_engine.cpp): Implemented direct Vulkan GPU offload for 1.58-bit ternary GEMV (bitnet_gemv_i2_s.comp), in-place RoPE (rope.comp), decode multi-head attention (attention_decode.comp), SwiGLU activation (swiglu_silu.comp), RMSNorm (rmsnorm_norm.comp), and residual add (residual_add.comp).
  • Permanent Model VRAM Residency Architecture: Pre-allocates unified GPU storage buffers for all 30 transformer layers (498 MB) and FP16 LM Head (626 MB) at initialization, completely eliminating host-to-device bus traffic during autoregressive token evaluation.
  • Full-Pipeline On-Chain Token Execution (DispatchFullTokenChain): Fuses the entire 30-layer pipeline into a single VkCommandBuffer submission and single fence wait per token, cutting driver submission overhead by 99.4%.
  • FP16 LM Head GPU Offload (bitnet_gemv_f16.comp): Offloads 128,256-dim vocabulary projection with unpackHalf2x16 SIMD dot products, saving ~80 ms per token on mobile SoCs.
  • Empirical Benchmarks: Validated on Samsung Galaxy S25 Adreno 830 (17.56 tok/s, 12.58x speedup) and Samsung Galaxy A35 Mali-G68 (3.47 tok/s, 5.94x speedup).
  • Unified BitnetAdapter (python/ameva_runtime/adapters/bitnet.py): First-class native integration enabling from ameva_runtime.adapters.bitnet import BitnetAdapter.
