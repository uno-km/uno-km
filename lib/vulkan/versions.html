Version Archive & Changelog

Changelog history and immutable releases

v1.1.0 - Galaxy A35 Validation & CTypes Pointer Patch

Production Release (Latest) 2026-09-01
  • Real-Device Galaxy A35 Validation: Certified 12-stage hardware diagnostic hierarchy and Vulkan 1.4 API negotiation on Samsung Galaxy A35 5G (Exynos 1380, ARM Mali-G68 GPU).
  • CTypes Struct Pointer Patch: Corrected struct pointer allocations to ctypes.pointer to fix TypeError in doctor.py.
  • Dynamic Topology Thread Optimization: Added CPU topology inspection in LlamaCppAdapter targeting big-core clusters (-t 4) on mobile octa-core SoCs.
  • Strict Vulkan 3-Tier Execution Mode: Fail-Fast protection for explicit --device vulkan requests without silent CPU masking.

v1.0.0 - Initial Production Release

Initial Release 2026-08-15
  • Initial production release of ameva-vulkan-runtime.
  • 12-Stage Diagnostic Suite (Doctor) from V0 loader open to V11 model inference.
  • Multi-modality adapters for STT, TTS, Diffusion, BitNet, Vision, and LlamaCpp.
  • Cross-platform Bionic ICD driver loader (/system/lib64/libvulkan.so).
