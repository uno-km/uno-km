API 인터페이스 명세서 & 아키텍처 규격

클래스 시그니처, SmartRouter 토폴로지 분기 및 6-모달리티 어댑터 API (AMEVA-Runtime)

Release: v2.7.7
핵심 가치 제안 (Why It Matters)

복잡한 C++ Vulkan API 및 벤더 드라이버 코드를 직접 다루지 않고도, 단일 Python/JS 인터페이스로 기기 토폴로지를 자동 판별하여 최고 속도의 AI 가속 파이프라인을 구동합니다.

1. 최상위 실행 인터페이스 (Top-Level API)

함수 / 메서드 시그니처 설명 및 엔지니어링 동작
ameva.run() run(model: str, prompt: str, max_tokens: int = 128, **kwargs) -> InferenceResult 지정한 모델과 프롬프트에 대해 하드웨어 최적 백엔드(Vulkan/OpenCL/NEON)를 자동 선택하여 추론을 실행합니다.
ameva.detect_hardware() detect_hardware() -> HardwareProfile 커널 디바이스 노드(/dev/kgsl-3d0, /dev/mali0)를 조회하여 SoC, GPU 벤더, 드라이버 버전을 반환합니다.
vulkan.Doctor() Doctor.run_self_test(verbose: bool = False) -> DiagnosticReport Bionic 드라이버 로드, 특수화 상수 지원 여부, VRAM 할당 등 12단계 하드웨어 진단을 수행합니다.

2. SmartRouter & 모달리티 어댑터 (Modality Adapters)

어댑터 클래스 타깃 모달리티 연동 네이티브 엔진 및 하드웨어 메커니즘
LlamaCppAdapter LLM (대형 언어 모델) GGUF 100% VRAM 레이어 오프로드 (ngl=999), Adreno 600 Flash Attention 자동 방어 (-fa 0).
SttAdapter STT (음성 인식) Whisper Large-v3-Turbo Vulkan Compute, Adreno 830 JIT 방어 (mul_mat_vec_max_cols=2).
TtsAdapter TTS (음성 합성) Sherpa-NCNN / MeloTTS, Bionic Direct Vulkan 바인딩 및 HiFi-GAN 32MB 시간축 타일링.
DiffusionAdapter 이미지 생성 (Diffusion) Z-Image Turbo 6.0B DiT / SDXS, Flash Attention (--diffusion-fa) 및 VAE 타일링 디코딩.
VisionAdapter 비전 & VLM (Multimodal) CLIP / MobileVLM / LLaVA 비전 인코더 텐서 가속 파이프라인.
BitNetAdapter BitNet (1.58-bit LLM) Microsoft BitNet b1.58 2B-4T i2_s 삼항 가중치 Vulkan & ARM NEON 가속.

3. 예외 및 실패 대응 (Fail-Fast Exceptions)

예외 클래스 발생 원인 시스템 안전 조치
AmbiguousModelMatchError 모델 검색 경로에 복수의 모호한 가중치 파일이 발견된 경우 침묵 추측(Silent Guessing)을 전면 차단하고 명시적 파일 경로 지정을 요구함.
SiliconIncompatibleError 하드웨어 Vulkan Compute 기능(1.1+)이 미지원되는 레거시 SoC인 경우 CPU NEON 고속 벡터 연산 백엔드로 안전 분기 처리.
VulkanDeviceLostError 셰이더 무한 루프 또는 VRAM 한도 초과로 GPU TDR 하드웨어 리셋 발생 시 커널 파라미터(enforce_medium_matmul) 자동 재조정 및 크래시 방어.
