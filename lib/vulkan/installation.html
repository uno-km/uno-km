설치 및 환경 구성 가이드

모바일 하드웨어 가속, 1-Click 네이티브 엔진 프로비저닝 및 의존성 관리 (AMEVA-Runtime)

Release: v2.7.7
핵심 가치 제안 (Why It Matters)

복잡한 C/C++ 네이티브 크로스 컴파일 과정 없이, Two-Track 공개 레지스트리를 통해 검증된 6대 모달리티 Vulkan 가속 엔진 바이너리를 토큰 없이 1-Click으로 자동 설치합니다.

1. 공식 패키지 매니저 설치

# Python SDK (PyPI)
pip install ameva-runtime

# Node.js / TypeScript SDK (NPM)
npm install @ameva/runtime

2. 1-Click 네이티브 엔진 자동 프로비저닝 (CLI)

패키지 설치 후 제공되는 ameva CLI를 통해 Android Bionic 최적화 가속 엔진을 즉시 배포할 수 있습니다:

# 6대 모달리티 가속 엔진 전수 자동 설치
ameva install --all

# 또는 특정 모달리티 엔진만 선택 설치
ameva install --modality diffusion   # Stable Diffusion & DiT Vulkan Engine
ameva install --modality stt         # Whisper STT Vulkan Engine
ameva install --modality llm         # LLaMA C++ Vulkan Engine
ameva install --modality tts         # Sherpa-NCNN Neural Voice Engine
ameva install --modality bitnet      # BitNet 1.58-bit Acceleration Engine

# 12단계 단말기 하드웨어 무결성 자가 진단 실행
ameva doctor

3. 필수 시스템 요구사항

구분 최소 요구 사양 권장 사양
운영체제 Android 10+ (Termux ARM64) / Linux aarch64 Android 14 ~ 16 (Bionic Direct Vulkan)
