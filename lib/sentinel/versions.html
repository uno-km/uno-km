v2.1.0 - Multi-Axis Risk Observation & Edge Provider Standard (Current)

Released: August 2026 • Status: Production LTS

  • Multi-Axis Semantic Separation (v2.0 Schema): Decoupled monolithic triage into independent riskLevel, actorClaim, verification, and decision dimensions. Absences of automation signatures default to UNKNOWN.
  • Enterprise Edge Provider Adapters: Added modular adapter architecture (CloudflareEdgeAdapter, VercelEdgeAdapter, FastlyEdgeAdapter, GenericEdgeAdapter) with explicit capabilities contracts.
  • Trust Boundary Verification Guardrail: Enforced strict network validation rules—verified bot escalation requires authenticated edge-to-origin channels and direct-origin blocking.
  • Zero Raw IP Persistence in Application Tables: IPv4/IPv6 masking (maskIpAddress()), coordinate logging dropped (null), free-text click logging sanitized with strict target_type enum.
  • Fail-Open Architecture: Ingestion errors return HTTP 200 with degraded safe allowance; 55+ automated multi-dimension test scenarios verified.
  • Signal Coverage Precision: Replaced hardcoded confidence with a dynamic 5-category availability metric on observability dashboard.

v1.0.4 - Target Discrimination Architecture

Released: August 2026 • Status: Superseded by v2.1

  • Live Observability Dashboard: Integrated forensic session telemetry, WebGL fingerprinting, memory heap profiling, and real-time journey tracing.
  • Signal Coverage Tooltip: Enhanced client-side heuristics with preliminary actorClaim breakdown.

v1.0.0 - Target Discrimination Standard

Released: August 2026 • Status: Production

  • Deterministic 0~100 Scoring Engine: Algebraic threat calculation based on browser execution environment consistency.
  • Cryptographic HMAC-SHA256 Signatures: Tamper-proof token generation for server-side authorization.
  • 3-Tier Master SSOT Architecture: Unified header, streamlined documentation, and 13-language i18n DOM engine.
  • AI Agent Feeds: Machine-readable context endpoints (llms.txt, llms-full.txt).

v0.9.0 - Core Signal Architecture (Beta)

Released: July 2026 • Status: Archived

  • Initial prototype of browser internal capability detection and automated bot discrimination.
  • Benchmarked across Chromium, WebKit, and Gecko browser engines with zero memory leakage.
