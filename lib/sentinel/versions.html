버전 아카이브 & 릴리즈 이력 (Changelog)

불변의 릴리즈 내역 및 시맨틱 버저닝 마일스톤 (AMEVA-Sentinel)

Release: v2.3.0

v2.3.0 - Hierarchical Cost Guard & Active Defense Tarpit

Production Release 2026-09-28
  • Hierarchical Cost Guard Engine: 요청 페이로드 크기 및 응답 버짓(Response Budget)을 실시간으로 제한하여 클라우드 LLM 및 백엔드 연산 비용 폭주 방어.
  • Active Defense Tarpit Engine: 고위험 봇 클라이언트에 대해 연결을 즉시 끊지 않고 HTTP 소켓 스트리밍을 인위적으로 지연(최대 5,000ms)시켜 공격자 자원을 소모시키는 타르핏 탑재.
  • Redis Token Bucket & Threat Aggregator: 분산 환경에서의 계층형 토큰 버킷과 인메모리 비상 로컬 폴백 저장소(LocalEmergencyBudgetStore) 통합.

v2.2.0 - Dual-Runtime SDKs (TypeScript & Python) & Shadow Mode

Stable Release 2026-08-26
  • TypeScript & Python 듀얼 런타임 패리티: Node.js(Express, Fastify, Next.js) 및 Python(FastAPI, Starlette, Flask) 완벽 지원.
  • 섀도우 모드(Shadow Mode) 가드레일: 프로덕션 트래픽에 영향을 주지 않고 백그라운드에서 위험도를 사전 관측·기록하는 섀도우 평가 체계 확립.
  • 프라이버시 중심 마이크로 인터랙션 분석: 브라우저 좌표 수집 없이 Shannon 엔트로피 지터와 DOM 상호작용 신호만으로 정상 사용자 판별.

v2.0.0 - Core Observability Framework Overhaul

Major Milestone 2026-07-15
  • 결정론적 HMAC-SHA256 클라이언트 인증 토큰 시스템 구축.
  • 서브 밀리초(<0.25ms) 클라이언트 브라우저 신호 도출 엔진 탑재.
  • Cloudflare, Fastly, AWS CloudFront 에지 헤더 정규화 지원.
