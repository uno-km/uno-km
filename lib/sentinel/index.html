소개 및 아키텍처 개요

프라이버시 중심 제로 데이터 수집 웹 브라우저 관측성 및 결정론적 0~100 위협 채점 SDK

Release: v2.3.0
1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# Node.js 공식 패키지 매니저 (TypeScript / 브라우저 & 백엔드 SDK)
npm install @ameva/sentinel

# Python 공식 패키지 매니저 (FastAPI / Flask / Django 미들웨어)
pip install ameva-sentinel

기술적 당면 과제

기존의 상용 봇 탐지 도구들은 사용자의 마우스 움직임, 키보드 입력 속도, 개인식별정보(PII)를 과도하게 수집하여 프라이버시를 침해하고 웹사이트 로딩 속도를 저하시킵니다.

아키텍처 혁신 및 기술 돌파구

사용자 입력을 단 1바이트도 캡처하지 않고 브라우저 DOM 구조의 무결성과 Shannon 엔트로피 신호만을 로컬에서 평가하여, 0~100 결정론적 위협 점수와 암호화 HMAC 토큰을 즉시 생성합니다.

핵심 가치 제안 (Why It Matters)

복잡한 보안 설정 없이 패키지 하나로 설치 완료. 사용자 개인정보를 1바이트도 훔쳐보지 않으면서도 악성 봇과 공격자만을 칼같이 걸러냅니다.

주요 기능 및 하드웨어 강화

100% 무데이터(0-Data) 개인정보 보호

사용자의 어떠한 텍스트 입력이나 개인정보도 수집하지 않아 완벽한 개인정보 보호 컴플라이언스를 달성합니다.

결정론적 0~100 위협 채점

휴리스틱과 엔트로피 연산을 조합하여 모호함 없는 명확한 위험 수치를 산출합니다.

HMAC-SHA256 암호화 토큰 검증

서버와 클라이언트 간 위조 불가능한 인증 토큰을 발행하여 중간자 공격을 차단합니다.

브라우저 표준 완벽 호환

Chrome, Safari, Firefox 등 모든 최신 웹 브라우저 환경에서 동일하게 동작합니다.

초경량 1ms 미만 실행 레이턴시

방문자가 로딩 지연을 전혀 인지할 수 없는 초고속 검증 속도를 자랑합니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
Structural DOM Parser 변조된 스크립트 주입 및 악성 아이프레임 탐지 프로덕션 안정
HMAC-SHA256 Signer 암호화 무결성 서명 및 타임스탬프 토큰 생성기 프로덕션 안정
Shannon Entropy Calculator 인간다운 상호작용 지터 엔트로피 정밀 계산 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

# AMEVA-Sentinel 파이썬 서버 검증 예제
import hmac, hashlib

def verify_sentinel_token(payload: bytes, token: str, secret: bytes) -> bool:
    expected = hmac.new(secret, payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, token)

is_valid = verify_sentinel_token(b"sample_payload", "8f3d6c...9a", b"prod_secret_key")
print(f"[Sentinel] 클라이언트 토큰 인증 결과: {is_valid}")

Node.js (npm) 사용 예제

const { SentinelEngine } = require('ameva-sentinel');

async function main() {
  const sentinel = new SentinelEngine({ secret: 'prod_secret_key', strictEntropy: true });
  const evalResult = await sentinel.evaluateSignals();
  console.log(`[Sentinel] 위협 점수: ${evalResult.score} / 100`);
  console.log(`[Sentinel] 인증 HMAC 토큰: ${evalResult.token}`);
}

main();
