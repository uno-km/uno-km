Installation & Setup Guide

npm, CDN, and browser integration for the privacy-first risk scoring SDK

⚡ Zero-Compilation — Works Everywhere

AMEVA-Sentinel is a pure JavaScript/TypeScript library. No native compilation, no binary dependencies. Install once and run identically on Node.js, Browser, Deno, and Bun.

1. Package Manager Installation

1.1 npm / Yarn / pnpm

# npm
npm install ameva-sentinel

# Yarn
yarn add ameva-sentinel

# pnpm
pnpm add ameva-sentinel

1.2 CDN — No Build Step Required

<!-- jsDelivr (recommended) -->
<script src="https://cdn.jsdelivr.net/npm/ameva-sentinel/dist/sentinel.min.js"></script>

<!-- unpkg -->
<script src="https://unpkg.com/ameva-sentinel/dist/sentinel.min.js"></script>

<!-- ESM via skypack -->
<script type="module">
  import { Sentinel } from 'https://cdn.skypack.dev/ameva-sentinel';
</script>

3. TypeScript Support

# TypeScript types are bundled — no @types/* package needed
npm install ameva-sentinel
# tsconfig.json: "moduleResolution": "bundler" or "node16"

3.1 TypeScript Import

import { Sentinel, SentinelConfig, EvaluationResult } from 'ameva-sentinel';

const config: SentinelConfig = {
  hmacSecret: process.env.SENTINEL_SECRET!,
  shadowMode: false,
  riskThreshold: 60
};

const sentinel = new Sentinel(config);
const result: EvaluationResult = await sentinel.evaluate(req);

4. Framework-Specific Installation

4.1 Express.js Middleware

npm install ameva-sentinel express
# Then see Quickstart → Recipe 1 for middleware registration

4.2 Next.js / Vercel Edge

npm install ameva-sentinel
# Add to next.config.js: experimental.serverComponentsExternalPackages: []
# Deploy to Vercel Edge Runtime natively

4.3 FastAPI / Python (via ameva-sentinel-py)

pip install ameva-sentinel
# Python SDK wraps the Node.js core via subprocess bridge
# See API Reference for Python-specific async patterns

5. Verification

# Verify installation
node -e "const s = require('ameva-sentinel'); console.log('Sentinel v' + s.VERSION + ' OK')"

# Run built-in self-test suite
npx ameva-sentinel --self-test
