Installation & Setup Guide

Non-root Chromium browser automation on Android Termux — zero sudo required

⚡ Non-Root Architecture

Termux-Playwright runs Chromium in a fully non-root, Bionic-native environment. No proot, no fakeroot, no virtualization. The browser sandbox is disabled only at the OS userspace boundary already enforced by Android SELinux.

1. Quick Install

1.1 Python (PyPI)

# Install SDK
pip install termux-playwright

# Download non-root Chromium binary for ARM64
termux-playwright install --arch arm64

# Verify installation
termux-playwright doctor

1.2 Node.js (npm)

npm install termux-playwright

# Auto-provision Chromium binary
npx termux-playwright install

# Verify
npx termux-playwright doctor

2. Termux Prerequisites

# Required Termux packages
pkg update && pkg install -y \
  python nodejs \
  libexpat libjpeg-turbo libpng \
  nss libx11 libxcomposite libxdamage \
  libxrandr libatk at-spi2-atk libgtk3

# Storage permission (required for screenshot save)
termux-setup-storage

3. ARM64 Prebuilt Binary Matrix

4. Environment Variables

# ~/.bashrc or ~/.zshrc
export TERMUX_PLAYWRIGHT_BINARY="$HOME/.termux-playwright/chromium"
export TERMUX_PLAYWRIGHT_NO_SANDBOX=1       # Required for non-root
export TERMUX_PLAYWRIGHT_HEADLESS=1         # Default: headless mode
export TERMUX_PLAYWRIGHT_TIMEOUT=30000      # Navigation timeout ms

5. Verification

termux-playwright doctor
# Expected output:
# [PASS] ARM64 binary: /data/data/com.termux/files/home/.termux-playwright/chromium
# [PASS] No-sandbox mode enabled
# [PASS] Headless GPU available (SwiftShader)
# [PASS] Page navigation test: https://example.com → 200 OK (1234ms)
# → All checks passed. Termux-Playwright is ready.
