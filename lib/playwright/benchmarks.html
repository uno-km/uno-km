3. Parallel Crawl Throughput (3 concurrent pages)

# Benchmark: 30 URLs, 3 concurrent pages
# python bench_crawl.py --urls 30 --concurrent 3

Results on Galaxy S20 (4GB RAM allocation, 3 pages max):
  Total URLs crawled:  30
  Total time:          42.3s
  Throughput:          0.71 URLs/s
  Peak memory (RSS):   420 MB
  CPU utilization:     ~65% (Snapdragon 865 big cores)
