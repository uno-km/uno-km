Termux-Playwright

Non-Root Real Chromium Automation & CDP Engine for Android Termux

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-playwright
# or:
npm install termux-playwright

The Engineering Challenge

Official browser automation drivers fail on Android Termux due to missing X11/Wayland servers and sandboxing constraints.

The Architectural Breakthrough

Controls genuine Chromium processes via direct Chrome DevTools Protocol (CDP) WebSocket sessions on Android Bionic libc without root.

Key Capabilities & Built-in Hardening

Deterministic 0-Drift Output

Bit-exact floating-point precision verified across heterogeneous ARM64 & WebGPU hardware.

Zero Cloud Egress Architecture

Operates 100% on the local client without external network telemetry leaks.

Memory Leakage Protection

Weakref lifetime management preventing GPU VRAM / system RAM leaks.

Canonical Usage Example

from termux_playwright import TermuxBrowser
browser = TermuxBrowser.launch(headless=True)
page = browser.new_page()
page.goto('https://uno-km.vercel.app')
import { TermuxBrowser } from 'termux-playwright';
const browser = await TermuxBrowser.launch({ headless: true });
