퀵스타트 및 실행 레시피

즉시 실행 가능한 1줄 CLI 명령어, 최소 코드 레시피 및 하드웨어 검증 모델 프로파일 (Termux-Playwright)

핵심 가치 제안 (Why It Matters)

명령어 한 줄이면 스마트폰이 알아서 웹사이트에 접속해 글을 읽고 화면을 캡처해 옵니다.

1. 1줄 CLI 즉시 실행

기본값이 사전 구성되어 있어 별도 설정 없이 바로 실행할 수 있습니다:

termux-playwright scrape --url https://news.google.com --selector 'article h3'

2. Python 최소 실행 레시피

from termux_playwright import PlaywrightEngine

# 1. 스텔스 모바일 브라우저 세션 초기화
with PlaywrightEngine(headless=True, stealth=True) as browser:
    page = browser.new_page()
    page.goto("https://news.google.com")
    
    # 2. 웹페이지 제목 및 주요 기사 헤드라인 수집
    titles = page.query_selector_all("article h3")
    print(f"[수집된 헤드라인 {len(titles)}건]:")
    for t in titles[:5]:
        print(f" - {t.inner_text()}")
    
    # 3. 모바일 화면 캡처
    page.screenshot(path="news_mobile.png")
    print("[완료] 스크린샷이 news_mobile.png로 저장되었습니다.")

3. JavaScript / Node.js 최소 실행 레시피

const { PlaywrightEngine } = require('termux-playwright');

async function main() {
  const browser = new PlaywrightEngine({ headless: true });
  await browser.launch();
  const page = await browser.newPage();
  await page.goto('https://news.google.com');
  console.log(`[페이지 제목]: ${await page.title()}`);
  await browser.close();
}

main();

5. 하드웨어 장애 대응 및 자동 복구 프로토콜

발생 증상 (에러 로그) 근본 원인 (Root Cause) 엔지니어링 조치 프로토콜
VK_ERROR_DEVICE_LOST Mali Valhall 아키텍처 정수 나눗셈 보폭 0 절삭 무한 루프 발생. --enforce-medium-matmul 옵션으로 워크그룹 크기 128 커널을 강제 바인딩합니다.
VK_ERROR_UNKNOWN (-13) 스냅드래곤 Adreno JIT 컴파일러 레지스터 할당 한도 초과. 특수화 상수 mul_mat_vec_max_cols = 2로 고정하여 안전하게 실행합니다.
배터리 구동 시 지연시간 급증 안드로이드 OS의 배터리 세이버가 CPU 빅코어를 오프라인 전환함. 스레드 친화도(thread_affinity=[4,5,6,7])를 통해 고성능 빅코어에 프로세스를 고정합니다.
프로세스 종료 후 VRAM 미반납 비정상 종료로 인한 POSIX 공유 메모리 핸들 잔류. RAII 소멸자를 호출하거나 shm_unlink()를 통해 좀비 버퍼를 즉시 회수합니다.
