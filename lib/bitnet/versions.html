Latest Production Release

v1.4.0 - Native Vulkan Compute GPU Acceleration, Permanent VRAM Residency & Dynamic C ABI — 2026-09-07

  • Native Vulkan Compute GPU Engine (via AMEVA-Runtime): Dedicated SPIR-V compute kernels for BitNet 1.58-bit ternary GEMV (bitnet_gemv_i2_s.comp), FP16 LM Head offload (bitnet_gemv_f16.comp), RoPE, Attention Decode, SwiGLU, RMSNorm, and Residual summation.
  • Llama.cpp-Style Permanent Model VRAM Residency: Pre-allocates unified GPU storage buffers for all 30 transformer layers (498 MB) and LM Head (626 MB) at initialization, completely eliminating host-to-device bus traffic during autoregressive token evaluation.
  • Full-Pipeline On-Chain Token Execution (DispatchFullTokenChain): Fuses the entire 30-layer pipeline into a single VkCommandBuffer submission and single fence wait per token, eliminating 99.4% of driver submission overhead.
  • C ABI Dynamic Parameter Synchronization (bitnet_set_params): Thread-safe runtime update for temperature, top_p, top_k, repeat_penalty, and stop tokens without context re-initialization.
  • Telemetry Ground Truth Hardening: Fixed prompt_tokens calculation in GenerationMetrics to accurately report actual token counts across streaming and batch runs.
  • Empirical Real-Device Benchmarks: Documented verified physical device metrics on Galaxy S25 Adreno 830 (17.56 tok/s, 12.58x speedup) and Galaxy A35 Mali-G68 (3.47 tok/s, 5.94x speedup).
