Complete API Reference & C ABI

Complete programmatic reference for Python SDK, Node.js Gateway, and C ABI.

1. Python SDK Reference (termux_bitnet)

Class / MethodSignatureDescription
BitNetConfig (model_path, n_threads=8, n_ctx=2048, temperature=0.7, top_p=0.95, top_k=40, min_p=0.05, repeat_penalty=1.15, seed=0) Immutable configuration dataclass for runtime parameters.
BitNetEngine.__init__ (config: BitNetConfig) Loads native shared library and initializes context.
BitNetEngine.generate_stream (prompt: str, max_tokens: int = 128) -> Iterator[str] Yields generated tokens in real-time via C ABI streaming callback.
BitNetEngine.close () -> None Releases C++ context and frees KV cache memory.

2. Node.js Gateway Reference

Function / MethodSignatureDescription
createEngine(options) (options: BitNetOptions) => BitNetEngineInstance Instantiates engine wrapper managing native CLI/IPC child process.
engine.generateStream (prompt: string, maxTokens: number, onToken: (t: string) => void) => Promise<string> Streams output tokens asynchronously to the provided callback.

3. Native C ABI (termux_bitnet.h)

typedef struct {
    const char* model_path;
    int32_t     n_threads;
    int32_t     n_ctx;
    int32_t     n_batch;
    float       temperature;
    float       top_p;
    int32_t     top_k;
    float       min_p;
    float       repeat_penalty;
    uint32_t    seed;
} bitnet_params_t;

bitnet_params_t bitnet_default_params(void);
bitnet_context_t bitnet_init(const bitnet_params_t* params);
bool bitnet_generate_stream(bitnet_context_t ctx, const char* prompt, int32_t max_tokens, bitnet_token_callback_t cb, void* user_data);
void bitnet_free(bitnet_context_t ctx);
