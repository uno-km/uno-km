Installation & Environment Setup

Setting up Termux-BitNet on Android Termux (ARM64) and Linux environments.

Prerequisites on Android Termux

Ensure Python 3.9+ or Node.js 18+ and standard C++ build utilities are installed in Termux:

pkg update && pkg install -y python clang cmake make nodejs

1. Standard Package Installation

Option A: Python SDK (PyPI)

pip install termux-bitnet

Option B: Node.js npm Gateway

npm install termux-bitnet

2. Downloading Pre-Quantized 1.58-bit GGUF Models

Termux-BitNet includes a built-in model registry with resumable HTTP downloads:

# Download Microsoft 2.4B 1.58-bit flagship model (1.13 GB)
termux-bitnet download bitnet-2b

# Download Ultra-Lightweight 0.7B model (404 MB) for resource-constrained devices
termux-bitnet download bitnet-large

# Download High-Precision 3.3B model (730 MB)
termux-bitnet download bitnet-3b

3. Verifying Installation

Execute an automated verification check to confirm C++ NEON kernel initialization:

python -c "import termux_bitnet; print('Termux-BitNet Version:', termux_bitnet.__version__)"
