Installation & Setup Guide

Hardware acceleration, Termux setup, and dependency management

Target Environment & Prerequisites

Engineered for native execution on Android Termux (ARM64 / aarch64), Ubuntu/Debian ARM64, and Linux. Requires Python 3.8+ or Node.js 18+.

1. Android Termux One-Touch Setup (Recommended)

Update repository packages and install required native build toolchains in a single command:

# 1. Install toolchains and dependencies
pkg update -y
pkg install -y clang cmake git python python-pip openblas libandroid-execinfo nodejs

# 2. Pre-provision Python build tools (Bypasses PyPI build-isolation bottleneck)
pip install --upgrade setuptools wheel

# 3. Install termux-bitnet Python SDK & CLI
pip install --no-build-isolation termux-bitnet

2. Node.js Dual Engine Gateway (npm)

Install the ultra-lightweight Node.js thin gateway with dedicated CLI namespace:

# Global install without binary conflict (Provides termux-bitnet-js)
npm install -g termux-bitnet

3. Hardware SIMD Diagnostics Verification

Execute the diagnostic CLI to confirm ARM NEON and DotProd (vdotq_s32) hardware acceleration:

# Python CLI check
termux-bitnet info

# Node.js CLI check
termux-bitnet-js info

4. Source Installation from GitHub

git clone https://github.com/uno-km/termux-bitnet.git
cd termux-bitnet
chmod +x install.sh
./install.sh
