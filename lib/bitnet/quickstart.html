Quickstart & Execution Recipes

Standard usage patterns for CLI, Python SDK, Node.js, and C/C++ embedding.

1. Standalone CLI Streaming

Execute direct token streaming from the terminal:

termux-bitnet run -m ~/.cache/termux-bitnet/models/bitnet-2b-ggml-model-i2_s.gguf \
  -p "Explain the mathematical difference between 1.58-bit ternary and FP16 weights:" \
  -t 8 -c 2048 -n 256 --temp 0.7 --top-p 0.95 --repeat-penalty 1.15

2. Python SDK Streaming Pattern

from termux_bitnet import BitNetEngine, BitNetConfig

config = BitNetConfig(
    model_path="~/.cache/termux-bitnet/models/bitnet-2b-ggml-model-i2_s.gguf",
    n_threads=8,
    temperature=0.7,
    top_p=0.95,
    top_k=40,
    min_p=0.05,
    repeat_penalty=1.15,
)

with BitNetEngine(config) as engine:
    for token in engine.generate_stream("Write an ARM64 NEON assembly dot product loop:"):
        print(token, end="", flush=True)

3. Node.js Streaming Pattern

const { createEngine } = require('termux-bitnet');

async function run() {
  const engine = createEngine({
    threads: 8,
    temperature: 0.7,
    topP: 0.95,
    maxTokens: 256,
  });

  await engine.generateStream("Explain kernel fusion in one paragraph:", 256, (token) => {
    process.stdout.write(token);
  });
}

run();

4. Embedded C ABI (Zero Dependency)

#include "termux_bitnet.h"
#include <stdio.h>

int main() {
    bitnet_params_t params = bitnet_default_params();
    params.model_path = "/data/data/com.termux/files/home/.cache/termux-bitnet/models/bitnet-2b.gguf";
    params.n_threads = 8;
    params.temperature = 0.7f;

    bitnet_context_t ctx = bitnet_init(&params);
    bitnet_generate_stream(ctx, "Hello BitNet", 64, [](const char* token, int32_t id, void* user_data) {
        printf("%s", token);
        return true;
    }, NULL);

    bitnet_free(ctx);
    return 0;
}
