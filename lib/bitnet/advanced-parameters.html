1. Native Vulkan Compute Acceleration via AMEVA-Runtime

Version 1.4.0 integrates with dev/ameva-runtime to execute all 30 transformer layers and FP16 LM Head directly on mobile GPU hardware:

  • bitnet_gemv_i2_s.comp: 1.58-bit ternary matrix-vector product compute kernel.
  • bitnet_gemv_f16.comp: 626.2 MB FP16 LM Head output projection offloaded to GPU with unpackHalf2x16.
  • rope.comp, attention_decode.comp, swiglu_silu.comp, rmsnorm_norm.comp, residual_add.comp: Full transformer layer compute shaders.
  • DispatchFullTokenChain: Single VkCommandBuffer submission and single fence wait per generated token.

2. Dynamic C ABI Parameter Synchronization

The engine maintains thread-safe state synchronization under std::mutex, enabling runtime updates without reloading weights:

typedef struct {
    float temperature;
    float top_p;

    float presence_penalty;
    int32_t top_k;
    int32_t repeat_last_n;
    uint32_t seed;
