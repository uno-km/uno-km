2. Dynamic Activation Dispatcher (Squared ReLU vs SwiGLU)

The engine introspects layer tensors at load time to automatically branch activation functions without user intervention:

  • BitNet 2B-4T: Squared ReLU (relu(x)^2) coupled with Sub-LayerNorm (ffn_sub_norm).
  • Falcon-E-1B & Falcon3-7B: Standard SwiGLU (SiLU(x) * up) without Sub-LayerNorm.
