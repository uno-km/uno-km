소개 및 아키텍처 개요

ARM64 NEON SIMD 및 Vulkan GPU 기반 1.58비트 경량 LLM 온디바이스 추론 엔진

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install termux-bitnet

# Node.js 공식 패키지 매니저
npm install termux-bitnet

기술적 당면 과제

마이크로소프트의 1.58비트 3진 양자화 LLM(BitNet)은 모바일 환경에 이상적이지만, 안드로이드 Termux 환경에서 직접 빌드할 경우 Bionic libc 비호환, CMake 크로스 컴파일 장애, 동적 링커 충돌, 복잡한 ARM64 NEON 어셈블리 셋업 등 극심한 빌드 고통이 따릅니다.

아키텍처 혁신 및 기술 돌파구

사전 벡터화된 ARM64 NEON DotProd 커널과 AMEVA-Runtime Vulkan 컴퓨트 파이프라인을 단일 pip 및 npm 패키지로 완벽 패키징하여, 복잡한 컴파일 없이 단 한 줄로 설치하고 서브 250MB RAM 환경에서 최대 17.56 tok/s 초고속 추론을 지원합니다.

핵심 가치 제안 (Why It Matters)

외계어 같은 컴파일 에러와 밤샘 세팅의 고통은 이제 그만. 터미널 창에 딱 한 줄만 입력하면, 내 주머니 속 스마트폰이 서버 부럽지 않은 최첨단 초경량 인공지능 두뇌로 즉시 변신합니다.

주요 기능 및 하드웨어 강화

원클릭 무빌드 패키징

사전 검증된 안드로이드 ARM64 Bionic 네이티브 바이너리와 런타임을 pip 및 npm으로 직접 배포하여 Clang/CMake 툴체인 설정과 컴파일 오류를 원천 차단합니다.

순수 Vulkan GPU 가속 연산

AMEVA-Runtime의 SPIR-V 컴퓨트 셰이더(i2_s GEMV, RoPE, Attention Decode)를 결합하여 모바일 GPU에서 최대 12.58배 추론 가속을 실현합니다.

ARM64 NEON DotProd 정수 코어

수기 최적화된 vdotq_s32 어셈블리 커널을 통해 부동소수점 곱셈을 정수 덧셈/뺄셈으로 대체하여 배터리 발열과 전력 소비를 극적으로 줄입니다.

영구 VRAM 상주 및 제로 버스 병목

초기화 시 가중치와 언어 헤드를 통합 GPU 버퍼에 단 1회 상주시켜 토큰 생성 도중 호스트-디바이스 간 중복 메모리 전송을 완전히 제거합니다.

동적 파라미터 제어 및 약한 참조 GC

모델 재로딩 없이 온도(temperature), Top-P, 반복 페널티를 실시간 갱신하며, 약한 참조 수명 관리를 통해 메모리 누수를 방지합니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
1.58-Bit GEMV (i2_s) ARM64 NEON vdotq_s32 어셈블리 커널, 3진 정수 곱셈 벡터화 프로덕션 안정
Vulkan GPU Compute Pipeline SPIR-V i2_s 행렬-벡터 연산 셰이더, Adreno/Mali 타깃 가속 하드웨어 가속
RoPE & Attention Head 온디바이스 KV 캐시 순환 링 버퍼 및 어텐션 디코딩 프로덕션 안정
Memory Ring Buffer POSIX shm_open 기반 토큰 스트리밍 제로카피 파이프 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from termux_bitnet import BitNetEngine, BitNetConfig

# 1. 자동 디바이스 감지 설정 (Vulkan GPU -> CPU NEON)
config = BitNetConfig(
    model_path="~/.cache/termux-bitnet/models/bitnet-2b-i2_s.gguf",
    device="auto",
    temperature=0.7
)

# 2. 스트리밍 토큰 생성 실행
with BitNetEngine(config) as engine:
    print("[질문]: 인공지능의 미래를 한 줄로 설명해줘")
    for token in engine.generate_stream("인공지능의 미래를 한 줄로 설명해줘:"):
        print(token, end="", flush=True)
    print()

Node.js (npm) 사용 예제

const { createEngine } = require('termux-bitnet');

async function main() {
  const engine = createEngine({
    modelPath: '~/.cache/termux-bitnet/models/bitnet-2b-i2_s.gguf',
    device: 'auto',
    temperature: 0.7
  });

  console.log('[질문]: 인공지능의 미래를 한 줄로 설명해줘');
  await engine.generateStream('인공지능의 미래를 한 줄로 설명해줘:', 64, (tok) => {
    process.stdout.write(tok);
  });
  console.log('\n');
}

main();
