v1.5.5 - Unified 5-Backend Standardization & Architectural Alignment

Production Release (Latest) 2026-09-29
  • Unified 5-Backend Standard: Standardized synthesis acceleration engine choices to the ecosystem standard --device auto|gpu|vulkan|opencl|cpu.
  • Fail-Fast Parameter Policy: Enforced strict argument whitelist eliminating silent degradation or ambiguous heuristics.
  • Zero-Hardcoding Dynamic Resolution: Fully integrated 3-Tier package version resolution matching PyPI and NPM distributions.
  • Fleet Integrity Verification: Validated by 54 automated unit tests across G2P phonemizers, DSP formant synthesizers, and multilingual neural vocoders.

v1.5.0 - Native Vulkan Hardware Pipeline & Fail-Fast Architecture

Stable Release 2026-09-15
  • Bionic Native Vulkan Direct Binding: Permanently eliminated Termux Mesa llvmpipe CPU software emulator trap by dynamically binding /system/lib64/libvulkan.so, activating 100% native Qualcomm Adreno (KGSL) and ARM Mali GPU compute pipelines.
  • HiFi-GAN 32MB Memory Ceiling Resolution: Overcame mobile GPU 32MB maxBufferSize allocation limit in MeloTTS HiFi-GAN via temporal window slicing (T_chunk <= 819), preventing VK_ERROR_OUT_OF_DEVICE_MEMORY and driver TDR resets.
  • Piper VITS On-Chip SRAM Tiling: Integrated on-chip SRAM tiling architecture eliminating kernel crashes across all Exynos and Snapdragon hardware.
  • Strict Zero-Silent-Fallback & Anti-Deception: Completely excised CPU fallback heuristics and silent exception swallowing; raises explicit RuntimeError on hardware or memory faults.
  • Next-Gen MZ Neural Triad: Added first-class native architectures for Kokoro-82M (INT8 StyleTTS2), MeloTTS Universal Bilingual, and Supertonic 3 Flow Matching across 31 languages.
  • Empirical Fleet Verification: Ground-truth validated on Galaxy S22 (Adreno 730: 2,750ms, RTF 0.88x), S21 (Mali-G78: 560ms, RTF 0.18x), S20 (Mali-G77: 750ms, RTF 0.24x), and S25 (Adreno 830: 380ms, RTF 0.12x).
