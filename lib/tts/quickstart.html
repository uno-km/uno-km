퀵스타트 및 실행 레시피

즉시 실행 가능한 1줄 CLI 명령어, 최소 코드 레시피 및 하드웨어 검증 모델 프로파일 (Termux-TTS)

핵심 가치 제안 (Why It Matters)

글자만 적어 넣으면 1초 만에 귀에 쏙쏙 박히는 자연스러운 사람 목소리로 즉시 읽어줍니다.

1. 1줄 CLI 즉시 실행

기본값이 사전 구성되어 있어 별도 설정 없이 바로 실행할 수 있습니다:

termux-tts speak '안녕하세요, 온디바이스 AMEVA 음성 합성 엔진입니다.' --tier 4

2. Python 최소 실행 레시피

from termux_tts import TTSEngine

# 1. 4-Tier 복원형 TTS 엔진 초기화 (Vulkan GPU 가속)
engine = TTSEngine(tier=4, sample_rate=22050)

# 2. 텍스트 음성 합성 및 오디오 스트림 재생
print("[TTS] 고음질 음성 합성 시작...")
engine.speak("안녕하세요, 온디바이스 AMEVA 음성 합성 엔진입니다.")
engine.save_to_wav("output.wav", "성공적으로 온디바이스 음성 합성이 완료되었습니다.")

3. JavaScript / Node.js 최소 실행 레시피

const { TTSEngine } = require('termux-tts');

async function main() {
  const tts = new TTSEngine({ tier: 4 });
  await tts.speak('안녕하세요, 온디바이스 음성 합성 엔진입니다.');
}

main();

5. 하드웨어 장애 대응 및 자동 복구 프로토콜

발생 증상 (에러 로그) 근본 원인 (Root Cause) 엔지니어링 조치 프로토콜
VK_ERROR_DEVICE_LOST Mali Valhall 아키텍처 정수 나눗셈 보폭 0 절삭 무한 루프 발생. --enforce-medium-matmul 옵션으로 워크그룹 크기 128 커널을 강제 바인딩합니다.
VK_ERROR_UNKNOWN (-13) 스냅드래곤 Adreno JIT 컴파일러 레지스터 할당 한도 초과. 특수화 상수 mul_mat_vec_max_cols = 2로 고정하여 안전하게 실행합니다.
배터리 구동 시 지연시간 급증 안드로이드 OS의 배터리 세이버가 CPU 빅코어를 오프라인 전환함. 스레드 친화도(thread_affinity=[4,5,6,7])를 통해 고성능 빅코어에 프로세스를 고정합니다.
프로세스 종료 후 VRAM 미반납 비정상 종료로 인한 POSIX 공유 메모리 핸들 잔류. RAII 소멸자를 호출하거나 shm_unlink()를 통해 좀비 버퍼를 즉시 회수합니다.
