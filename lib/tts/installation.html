Installation & Setup Guide

Hardware acceleration, Termux setup, and dependency management

Standard Package Installation

Install the core Python or Node.js package directly from standard package repositories:

# Python (PyPI)
pip install termux-tts

# Node.js / TypeScript (NPM)
npm install termux-tts

Prerequisites on Android Termux

Ensure that the required system packages are installed in your Termux environment:

pkg update && pkg install -y termux-api pulseaudio sox clang

1-Click Automated Engine Provisioning

To enable Tier 4 Vulkan GPU neural speech synthesis without manual compilation or model downloading, run the built-in installer:

# Install High-Resolution Studio Tier (vits-piper-en_US-lessac-high-fp16, 22.05kHz)
termux-tts install --tier high

# Or install Medium Compact Tier (vits-piper-en_US-lessac-medium)
termux-tts install --tier medium

The provisioning script downloads the precompiled native ARM64 C++ binary (sherpa-ncnn-offline-tts-vulkan) from the official GitHub Release and verifies execution via an immediate self-test.
