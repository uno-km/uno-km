Complete API Reference

100% Full Class, Struct, and Method Documentation

Hardware WGSL Compute Kernel Bindings

All methods map directly to WebGPU compute pipelines with asynchronous promise resolution and zero-copy staging buffers.

1. WebGPU Tensor Class (forge.Tensor)

Member / Method Type Signature Description
Tensor(data, device='cpu', requires_grad=False) Constructor Allocates multidimensional tensor memory in CPU RAM or GPU VRAM.
.to(device) ('cpu' | 'gpu') -> Tensor Transfers tensor storage between host RAM and WebGPU buffer memory.
.numpy_async() () -> Promise[np.ndarray] Asynchronously maps GPU staging buffer and copies array data back to CPU without blocking UI thread.
.backward(gradient=None) (Tensor) -> None Executes backward pass traversing WGSL compute shader gradient operations.
.zero_grad() () -> None Clears accumulated gradient buffers for all leaf parameters.
.matmul(other) / @ (Tensor) -> Tensor WGSL 16x16 tiled matrix multiplication compute shader dispatch.

2. Neural Network Modules (forge.nn)

Class Name Parameters Forward Signature Description
nn.Module () *args -> Any Base module managing parameters, submodules, and .to('gpu') recursive transfers.
nn.Linear (in_features, out_features, bias=True) (x: Tensor) -> Tensor Applies linear transformation \( y = xW^T + b \) accelerated via WGSL shaders.
nn.RMSNorm (dim, eps=1e-6) (x: Tensor) -> Tensor Root Mean Square Layer Normalization running directly on WebGPU with fused scaling.
nn.LayerNorm (normalized_shape, eps=1e-5) (x: Tensor) -> Tensor Standard Layer Normalization over trailing dimensions.
nn.PositionalEncoding (d_model, max_len=512) (x: Tensor) -> Tensor Sinusoidal positional encoding precomputed in GPU buffer memory.
nn.MSELoss (reduction='mean') (pred, target) -> Tensor Mean squared error loss compute kernel with fused reduction.
nn.CrossEntropyLoss (reduction='mean') (logits, targets) -> Tensor Numerically stable LogSoftmax + NLLLoss fused compute shader.

3. Functional Operators (forge.functional)

Function Signature Description
scaled_dot_product_attention (q, k, v, is_causal=False) Fused Scaled Dot-Product Attention compute pipeline with optional lower-triangular causal mask.
silu / swish (x: Tensor) -> Tensor Elementwise SiLU activation function: \( ext{SiLU}(x) = x \cdot \sigma(x) \).
gelu (x: Tensor) -> Tensor Gaussian Error Linear Unit approximation compute kernel.
