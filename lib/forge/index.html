AMEVA-Forge

Browser-Native WebGPU Autograd Deep Learning Engine & Real-Time Interactive Studio

1-Line Quick Installation

Install the official package directly into your runtime:

pip install ameva

The Engineering Challenge

Running deep learning and autograd workloads in client browsers typically suffers from sluggish JavaScript CPU emulation and heavy GPU VRAM memory leaks.

The Architectural Breakthrough

Executes PyTorch-compatible dynamic tensor computations via raw WebGPU WGSL compute shaders with deterministic weakref buffer pooling and zero memory leaks.

Key Capabilities & Built-in Hardening

Pure WebGPU WGSL Compute Shaders

Direct GPU hardware dispatching for forward and backward passes with zero JS overhead.

PyTorch Syntax Compatibility

Supports familiar Tensor API, autograd DAG, backward(), and standard optimizers.

Leak-Free GPU Buffer Pooling

Weakref lifecycle management preventing VRAM exhaustion during long training runs.

Canonical Usage Example

import ameva as am

# 1. Initialize WebGPU tensor computation
device = am.device("webgpu" if am.cuda.is_available() else "cpu")
x = am.randn(64, 128, device=device, requires_grad=True)
w = am.randn(128, 10, device=device, requires_grad=True)

# 2. Forward pass and backpropagation
y = am.matmul(x, w).relu().sum()
y.backward()
print("Gradients computed on WebGPU:", w.grad.shape)

import { Tensor, Device } from "https://uno-km.github.io/uno-km/lib/forge/dist/forge.esm.js";

const dev = new Device("webgpu");
await dev.init();

const x = Tensor.randn([64, 128], { device: dev, requiresGrad: true });
const w = Tensor.randn([128, 10], { device: dev, requiresGrad: true });
const y = x.matmul(w).relu().sum();
y.backward();
console.log("WebGPU Gradient Output:", w.grad);
