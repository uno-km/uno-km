소개 및 아키텍처 개요

PyTorch 런타임 종속성 없는 순수 C++ 텐서 연산 코어 및 초경량 오토그라드(Autograd) 엔진

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install ameva

기술적 당면 과제

모바일 인공지능 애플리케이션 개발 시 2GB가 넘는 무거운 PyTorch 런타임으로 인해 앱 다운로드 용량이 폭증하고 메모리 로딩 속도가 극도로 저하되는 문제가 있었습니다.

아키텍처 혁신 및 기술 돌파구

수십 메가바이트의 순수 C++20 템플릿 메타프로그래밍과 ARM NEON 및 Vulkan 셰이더 직결 텐서 코어를 구축하여, 무의존성 초고속 자동 미분 및 추론 엔진을 완성했습니다.

핵심 가치 제안 (Why It Matters)

기가바이트 단위의 무거운 파이토치를 걷어내고, 불과 수십 메가바이트의 날렵한 C++ 엔진으로 모바일 인공지능을 가동합니다.

주요 기능 및 하드웨어 강화

2GB+ 파이토치 완벽 배제

수십 메가바이트의 순수 C++ 엔진으로 모바일 임베디드 환경에 완벽 최적화되었습니다.

PyTorch 호환 텐서 API

tensor.matmul(), tensor.backward() 등 친숙한 문법을 그대로 지원합니다.

메모리 풀링 재할당 오버헤드 0화

사전 할당된 텐서 버퍼 풀을 재사용하여 가비지 컬렉션 멈춤 현상을 완전히 제거했습니다.

락리스 공유 메모리 텐서 IPC

프로세스 간 텐서 데이터를 복사 없이 0.05ms 만에 초고속 공유합니다.

결정론적 비트 단위 재현성

이기종 모바일 기기 간에도 완벽히 동일한 연산 결과를 보장합니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
ARM NEON GEMM Core 128비트 SIMD 레지스터 타일링 기반 부동소수점 행렬 곱셈 프로덕션 안정
Vulkan Compute MatMul SPIR-V GPU 셰이더 기반 병렬 텐서 곱셈 파이프라인 하드웨어 가속
Tape-based Autograd Graph 동적 역전파 미분 그래프 추적 및 메모리 재사용 프로덕션 안정
Lockless Shm Ring Buffer 프로세스 간 텐서 통신용 공유 메모리 링 버퍼 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

import ameva

# 1. 네이티브 Vulkan 디바이스 상에 텐서 생성
x = ameva.randn([512, 512], device="vulkan", dtype=ameva.float16)
w = ameva.randn([512, 512], device="vulkan", dtype=ameva.float16)

# 2. 하드웨어 가속 행렬 곱셈 수행
y = ameva.matmul(x, w)
print(f"[AMEVA-Forge] 계산 완료 디바이스: {y.device} 형태: {y.shape}")

# 3. 역모드 자동 미분 역전파 실행
y.backward()
print(f"[AMEVA-Forge] x의 그래디언트 노름: {x.grad.norm().item():.4f}")

Node.js (npm) 사용 예제

// AMEVA-Forge C++ 코어 CLI 브리지 예제:
const { execSync } = require('child_process');

console.log('[AMEVA-Forge] C++ 텐서 벤치마크 실행 중...');
const res = execSync('ameva-forge eval --dim 1024 --device neon');
console.log(res.toString());
