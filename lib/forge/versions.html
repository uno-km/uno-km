Release: v1.0.1

v1.0.1 - Universal Plug & Play WebGPU AI Runtime & Model Hub

Production Release 2026-09-04
  • Plug & Play On-Device GGUF Model Hub: Hugging Face CDN URL 및 로컬 .gguf 파일 드래그 앤 드롭을 통한 브라우저 WebGPU VRAM 직결(Direct DMA). 32비트 WASM 2GB 메모리 락을 우회하여 브라우저 OOM 방지.
  • Universal Byte-Level BPE & SentencePiece Tokenizer: GGUF 메타데이터(tokenizer.ggml.tokens) 파싱을 통한 어휘 사전 구축 및 무손실 가역 인코딩/디코딩 보장.
  • Autoregressive Streaming Generator & Shifted Softmax Sampler: Shifted Exp 수치 안정화가 적용된 Top-K, Top-P, Temperature, Repetition Penalty 통합 샘플러 및 60fps 논블로킹 타자기 스트리밍.
  • Web Worker Background Neural Runner: 메인 렌더링 스레드와 연산 파이프라인을 완전 분리하여 UI 프레임 드랍 및 OS GPU TDR 타임아웃 차단.
  • Interactive Live WebGPU Studio & 6-Language i18n: demo.html 및 all-modal-studio.html 인터랙티브 챗봇/속도계 탑재, 6개 국어 100% 동기화.
  • 공식 배포 활성화: PyPI (pip install ameva-forge) 및 NPM (@uno-km/ameva-forge) 공식 등록.

v1.0.0 - Browser-Native WebGPU Autograd Core Engine

Initial Release 2026-08-20
  • 순수 WebGPU WGSL 기반 다차원 텐서 연산 커널(MatMul, RMSNorm, Softmax, RoPE) 최초 구축.
  • 동적 연산 그래프(DAG) 기반 Reverse-mode 자동 미분(Autograd) 엔진 탑재.
  • PyTorch 1:1 호환 forge.nn 및 forge.optim.AdamW 모듈 구현.
  • 6개 국어 실시간 i18n DOM 번역 엔진 연동.
