Production Release Lineage

All versions are validated with 100% automated regression suites testing WebGPU autograd accuracy against reference PyTorch.

v1.0.0 - WebGPU Production Standard (Current)

Released: August 2026 • Status: Production LTS

  • Interactive WebGPU Studio (demo.html): Integrated Pyodide Python 3.11 with live WebGPU compute shader dispatch.
  • Causal Masked FlashAttention: Native WGSL compute shader implementation of scaled dot-product attention.
  • RMSNorm & RoPE Modules: LLaMA-3 compatible modern transformer building blocks on client GPU.
  • Zero VRAM Leakage: WeakRef garbage collection and zero-copy staging ring buffer pool.
  • PyTorch-Compatible Syntax: torch.tensor, nn.Linear, optim.SGD, .backward().

v0.9.0 - Transformer & LayerNorm Milestone

Released: August 2026 • Status: Archived

  • Implemented multi-head attention and LayerNorm WGSL compute pipelines.
  • Added asynchronous Pyodide Python virtual filesystem mounting.

v0.5.0 - Core WebGPU Autograd Prototype

Released: July 2026 • Status: Archived

  • Initial prototype of browser-native automatic differentiation graph over WebGPU buffers.
