Installation & Setup Guide

Browser WebGPU and Python backend setup for the autograd tensor framework

⚡ Dual Runtime: Browser WebGPU + Python

AMEVA-Forge runs natively in any WebGPU-capable browser (Chrome 113+) with zero installation, and as a Python library for server-side or Termux use. Choose the runtime that matches your deployment target.

1. Browser — Zero Installation (CDN)

<!-- ESM module (recommended) -->
<script type="module">
  import { Tensor, nn, optim } from 'https://cdn.jsdelivr.net/npm/ameva-forge/dist/forge.esm.js';
  // WebGPU is automatically selected if available, falls back to CPU
  const x = Tensor.randn([32, 64]);
  const y = x.matmul(Tensor.randn([64, 10])).relu();
  console.log('Output shape:', y.shape);
</script>

<!-- UMD global (for non-module environments) -->
<script src="https://cdn.jsdelivr.net/npm/ameva-forge/dist/forge.umd.min.js"></script>

2. Python (PyPI)

# Install Python package
pip install ameva

# Verify GPU backend detection
python -c "
import ameva as forge
print('AMEVA-Forge', forge.__version__)
print('Backend:', forge.get_backend())   # 'webgpu', 'cuda', or 'cpu'
"

3. npm (Node.js / TypeScript)

npm install ameva-forge

# TypeScript types included
# import { Tensor, nn, optim, Device } from 'ameva-forge';

5. Verification — Live WebGPU Test

import { Tensor, Device } from 'ameva-forge';

// Query active compute device
const device = await Device.init();
console.log('Active device:', device.type);  // 'webgpu' | 'cpu'
console.log('VRAM budget:', device.memoryBudget, 'bytes');

// Smoke test: 1000×1000 matmul on GPU
const A = Tensor.randn([1000, 1000]);
const B = Tensor.randn([1000, 1000]);
const t0 = performance.now();
const C = A.matmul(B);
await C.sync();  // Force GPU sync
console.log(`1000×1000 matmul: ${(performance.now() - t0).toFixed(1)} ms`);
