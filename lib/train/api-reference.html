Complete API Reference

100% Full Class, Struct, and Method Documentation

Deterministic Closed-Form Signatures

All core classes and methods follow strict OpenSSF and CNCF compliance standards with typed signatures and bounded memory footprints.

1. Core Tensor Engine (termux_train.Tensor)

Member / Method Type Signature Description
Tensor(data, requires_grad=False, dtype=float32) Constructor Initializes an autograd-tracked multidimensional tensor from Python lists or NumPy ndarrays.
.backward(gradient=None) (Tensor) -> None Computes the reverse-mode gradient of the computation graph via topologically sorted DAG traversal.
.zero_grad() () -> None Resets the internal .grad buffer to None to prevent gradient accumulation.
.item() () -> float | int Extracts the scalar value of a single-element tensor as a standard Python primitive.
.numpy() () -> np.ndarray Returns a zero-copy or view reference of the underlying NumPy storage array.
.reshape(*shape) (*int) -> Tensor Returns a reshaped tensor view preserving continuous tensor memory layout.
.transpose(dim0, dim1) (int, int) -> Tensor Permutes two dimensions with exact backward gradient routing.
.matmul(other) / @ (Tensor) -> Tensor Performs matrix multiplication with automatic broadcast handling for batch dimensions.

2. Neural Network Modules (termux_train.nn)

Class Name Parameters Forward Signature Description
nn.Module () *args -> Any Base class for all neural network modules. Manages parameter registration and nested submodule hierarchies.
nn.Linear (in_features, out_features, bias=True) (x: Tensor) -> Tensor Applies affine transformation: \( y = xW^T + b \). Weights initialized via Kaiming uniform.
nn.LoRALinear (in_features, out_features, r=8, lora_alpha=16.0) (x: Tensor) -> Tensor Low-Rank Adaptation wrapper decomposing weight updates into \( \Delta W = rac{lpha}{r} (B \cdot A) \).
nn.Embedding (num_embeddings, embedding_dim) (indices: Tensor) -> Tensor Lookup table storing dense word/token embeddings with sparse gradient propagation.
nn.RMSNorm (dim, eps=1e-6) (x: Tensor) -> Tensor Root Mean Square Layer Normalization offering 1.4x faster training speed than standard LayerNorm.
nn.TransformerBlock (d_model, n_heads, d_ff, dropout=0.0) (x: Tensor) -> Tensor Pre-norm Transformer decoder block with RoPE multi-head attention and SwiGLU feedforward network.
nn.CrossEntropyLoss (reduction='mean') (logits, targets) -> Tensor Combines LogSoftmax and NLLLoss in a single numerically stable closed-form operator.
nn.MSELoss (reduction='mean') (pred, target) -> Tensor Measures mean squared error between prediction and ground-truth regression targets.

3. Optimization Algorithms (termux_train.optim)

Optimizer Hyperparameters Update Rule Characteristics
optim.SGD (params, lr=1e-3, momentum=0.9, nesterov=False) First-order stochastic gradient descent with Polyak momentum and velocity damping.
optim.Adam (params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8) Adaptive moment estimation maintaining first and second biased moment vectors.
optim.AdamW (params, lr=1e-3, betas=(0.9, 0.999), weight_decay=0.01) Decoupled weight decay regularization preventing degradation observed in standard Adam.

4. SafeTensors Checkpoint & Serialization (termux_train.runtime)

Function Arguments Description
save_safetensors (state_dict: dict, file_path: str) Serializes tensor dictionaries directly to immutable SafeTensors binary format with zero pickle security risk.
load_safetensors (file_path: str) -> dict Memory-maps and reconstructs SafeTensors checkpoint into live termux_train.Tensor objects.
