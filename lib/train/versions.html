v2.0.0 - Major Multimodal Engine & 44GB Disaggregated Cluster Virtual RAM Release

Production Major Release 2026-10-03
  • Added 6-Modality Target-Aware LoRA Training Hub (LLM, Diffusion, Vision VLM, Whisper STT, TTS, BitNet 1.58-bit).
  • Introduced Single-Device GPU Slicing Architecture (--vocab-slice, --chunk-layers, --stream-layers) preventing mobile watchdog timeouts.
  • Implemented 44GB Disaggregated Cluster Virtual RAM Pooling across heterogeneous mobile devices with 300MB Guard-Band protection.
  • Integrated client-side On-Device Reinforcement Learning (GRPO, DPO, PPO).
  • Delivered 100% Dual-Engine Parity across Python CLI, Node.js CLI, Python SDK, and Node.js SDK.
  • Zero-conversion SafeTensors adapter export directly consumable by ComfyUI, llama.cpp, termux-vision, termux-stt, termux-tts, and bitnet.cpp.
