Version Archive & Changelog

Changelog history and immutable releases

Production Release Track

Every release is published immutably on PyPI and cryptographically tagged on GitHub with automated regression testing.

v1.0.0 - Production General Availability (Current)

Released: August 2026 • Status: Production LTS

  • Native DAG Autograd Engine: Pure Python reverse-mode automatic differentiation with topological sort.
  • Low-Rank Adaptation (LoRA): Complete LoRALinear module with adapter isolation and SafeTensors serialization.
  • RoPE Transformer Decoder: Rotary positional embeddings, RMSNorm, and multi-head attention blocks.
  • Optimizers: Full implementations of SGD (with momentum), Adam, and AdamW.
  • SafeTensors Integration: Zero-pickle, zero-copy binary weights checkpoint engine.
  • Physical Testbed Verification: Benchmarked on Samsung Galaxy S25 / S20 with 0.00% memory leak.

v0.9.5 - LoRA Adapter I/O & Checkpoint Milestone

Released: August 2026 • Status: Archived

  • Added adapter weight merging utility (merge_lora()) for inference offloading.
  • Enhanced gradcheck analytical vs numerical gradient verification suite.

v0.9.0 - RoPE & Attention Blocks

Released: August 2026 • Status: Archived

  • Implemented multi-head attention with causal triangular masking.
  • Added precomputed sinusoidal rotary frequency table caches.

v0.8.0 - AdamW & Loss Functions

Released: July 2026 • Status: Archived

  • Added decoupled weight decay AdamW optimizer.
  • Integrated numerically stable CrossEntropyLoss and NLLLoss.

v0.5.0 - Core Tensor DAG Prototype

Released: July 2026 • Status: Archived

  • Initial prototype of Python autograd computation graph and backward traversal.
