소개 및 아키텍처 개요

안드로이드 Bionic ARM64 직접 구동 모바일 LoRA/QLoRA 경량 미세조정(Fine-Tuning) 엔진

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install termux-train

기술적 당면 과제

모바일 단말기에서 인공지능 모델을 훈련하는 것은 수 기가바이트의 거대한 메모리 역전파 연산과 심각한 배터리 발열로 인해 불가능한 것으로 여겨졌습니다.

아키텍처 혁신 및 기술 돌파구

그래디언트 체크포인팅(Gradient Checkpointing), 4비트 양자화 역전파, SafeTensors 제로카피 맵핑을 결합하여 안드로이드 스마트폰 메모리 안에서 직접 동작하는 초경량 LoRA 미세조정을 실현했습니다.

핵심 가치 제안 (Why It Matters)

비싼 서버나 클라우드 없이 내 스마트폰 안에서 나만의 맞춤 AI를 직접 훈련시키는 초경량 온디바이스 트레이닝 엔진입니다.

주요 기능 및 하드웨어 강화

Bionic ARM64 직접 역전파 연산

안드로이드 네이티브 환경에서 메모리 절감형 오토그라드 엔진을 직접 실행합니다.

메모리 절감 그래디언트 체크포인팅

중간 활성화 값을 디스크에 버리지 않고 순전파 시 즉각 재계산하여 메모리를 60% 이상 절약합니다.

SafeTensors 제로카피 가중치 저장

훈련 완료된 LoRA 어댑터를 안전하고 빠른 SafeTensors 포맷으로 즉시 저장합니다.

발열 보호 지능형 스로틀링 가드

단말기 배터리 온도가 40도를 넘으면 스텝 간 미세 슬립을 주입하여 기기를 안전하게 보호합니다.

순수 C++ 경량 옵티마이저

AdamW 및 8-bit 양자화 옵티마이저를 탑재하여 메모리 소비를 최소화했습니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
LoRA Forward/Backward Kernel ARM NEON 가속 저순위 행렬 곱셈 및 그래디언트 누적 프로덕션 안정
Quantized Backprop Engine 4비트 양자화 가중치를 통한 역전파 오토그라드 프로덕션 안정
SafeTensors Zero-Copy IO 메모리 맵핑 기반 고속 가중치 저장/불러오기 프로덕션 안정
Thermal Safety Controller 배터리 온도 센서 연동 실시간 학습 속도 제어 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from termux_train import TrainEngine, LoRAConfig

# 1. 온디바이스 LoRA 훈련 설정
config = LoRAConfig(
    base_model="./qwen-0.5b.gguf",
    rank=8,
    alpha=16,
    learning_rate=2e-4,
    gradient_accumulation_steps=4
)

# 2. 온디바이스 파인튜닝 루프 실행
with TrainEngine(config) as trainer:
    trainer.load_dataset("./dataset.jsonl")
    print("[Termux-Train] 온디바이스 훈련 루프 시작...")
    for epoch, loss in trainer.train(epochs=3):
        print(f"에포크 {epoch} 완료 - 최종 손실값: {loss:.4f}")
    trainer.save_adapter("./adapters/custom_lora.bin")

Node.js (npm) 사용 예제

// Node.js CLI 브리지 실행 예제:
const { execSync } = require('child_process');

console.log('[Termux-Train] 훈련 CLI 실행 중...');
const stdout = execSync('termux-train fine-tune --model ./qwen-0.5b.gguf --data ./dataset.jsonl --rank 8');
console.log(stdout.toString());
