삼성 갤럭시 실기기 기반 C SafeTensors DAG Autograd 및 LoRA 온디바이스 훈련 실측치 (Termux-Train)

핵심 가치 제안 (Why It Matters)

클라우드 GPU 서버 없이 내 스마트폰 CPU 및 ARM64 NEON SIMD만으로 SafeTensors 텐서 역전파(Backpropagation)와 LoRA 파인튜닝을 수행할 때의 실제 훈련 속도와 메모리 점유 실측치입니다.

1. 단말기 칩셋별 순방향 / 역전파 훈련 스텝 지연시간

테스트 단말기 SoC 및 CPU 아키텍처 순방향 (Forward) 역전파 (Backward) 스텝당 총 훈련 시간 DRAM 메모리 점유
삼성 갤럭시 S25 스냅드래곤 8 Elite (Oryon x8 코어) 14.2 ms 28.5 ms 42.7 ms / step 65 MB (SafeTensors mmap)
삼성 갤럭시 S21 엑시노스 2100 (Cortex-X1 + A78 x3) 38.6 ms 76.4 ms 115.0 ms / step 72 MB
삼성 갤럭시 S20 스냅드래곤 865 (Kryo 585 x8) 46.1 ms 92.8 ms 138.9 ms / step 70 MB
삼성 갤럭시 A35 엑시노스 1380 (Cortex-A78 x4) 58.2 ms 118.4 ms 176.6 ms / step 68 MB

훈련 단계 학습 에폭 (Epoch) 평균 교차 엔트로피 손실 (Loss) 그래디언트 노름 (Norm) 메모리 누수 여부

3. 벤치마크 재현 가이드

ARM64 NEON SIMD 텐서 커널 가속

순수 C로 작성된 SafeTensors DAG Autograd 연산 엔진이 ARM NEON 벡터 어셈블리로 행렬곱을 병렬화하여 파이썬 인터프리터 오버헤드를 원천 배제합니다.

제로-카피 mmap 가중치 로딩

SafeTensors 포맷을 메모리 맵(mmap) 방식으로 직접 참조하여 훈련 데이터셋 및 가중치 복제에 따른 램 낭비와 OOM 크래시를 방지합니다.
