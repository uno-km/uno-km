Installation & Setup Guide

Hardware acceleration, Termux setup, and dependency management

Hardware & System Prerequisites

Targeted for ARM64 Android Termux environments (Android 10+, kernel 4.19+ / 5.x / 6.x), Snapdragon 8 series, Exynos, Dimensity, or generic Linux aarch64. Requires Python 3.9+ or Node.js 18+.

Package Managers

# Install official wheel from PyPI
pip install --upgrade termux-train
# Install global CLI and client library from npm
npm install -g termux-train
# Zero-configuration bootstrap installer
curl -sSL https://raw.githubusercontent.com/uno-km/termux-train/main/install.sh | bash

Vulkan Hardware Acceleration Configuration

To enable Vulkan compute acceleration on Android Termux:

# Install Vulkan utilities and headers
pkg update && pkg install -y vulkan-tools mesa-vulkan-icd-freedreno

# Validate Vulkan hardware compute capabilities
vulkaninfo --summary

# Verify Termux-Train backend detection
termux-train info
