Installation & Setup Guide

Pure Python autograd DAG engine — zero native compilation, zero NumPy dependency

⚡ Pure Python — No Binary Compilation

Termux-Train implements the full autograd DAG and LoRA fine-tuning pipeline in pure Python (CPython 3.9+). No GCC, CMake, BLAS, or NumPy required. Runs on any ARM64 or x86_64 Python environment.

1. PyPI Installation

pip install termux-train

# Verify
python -c "import termux_train; print('Termux-Train', termux_train.__version__, 'OK')"

2. Optional Accelerators

# Optional: NumPy for 3-10x matrix multiply speedup (if available)
pip install termux-train[numpy]

# Optional: Export trained models to GGUF format
pip install termux-train[gguf]

# Optional: Weights & Biases experiment tracking
pip install termux-train[wandb]

3. Termux ARM64 Prerequisites

# Termux environment setup
pkg update && pkg install python

# Install Termux-Train
pip install termux-train

# Verify ARM64 SIMD acceleration status
python -c "from termux_train.backend import detect_backend; print(detect_backend())"
# Output: 'arm64-neon' or 'pure-python'

5. Post-Install Verification

python -c "
from termux_train import Tensor, Module, SGD
# Quick autograd smoke test
x = Tensor([2.0], requires_grad=True)
y = x ** 2 + 3 * x + 1  # y = x^2 + 3x + 1
y.backward()
print('dy/dx at x=2:', x.grad)  # Should print [7.0]
print('Autograd DAG: OK')
"
