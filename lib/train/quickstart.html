퀵스타트 및 실행 레시피

즉시 실행 가능한 1줄 CLI 명령어, 최소 코드 레시피 및 하드웨어 검증 모델 프로파일 (Termux-Train)

핵심 가치 제안 (Why It Matters)

텍스트 메모장 하나만 건네주면 스마트폰이 스스로 공부해서 내 말투를 쏙 빼닮은 AI로 성장합니다.

1. 1줄 CLI 즉시 실행

기본값이 사전 구성되어 있어 별도 설정 없이 바로 실행할 수 있습니다:

termux-train fine-tune --model ./qwen-0.5b.gguf --data ./dataset.jsonl --rank 8

2. Python 최소 실행 레시피

from termux_train import TrainEngine, LoRAConfig

# 1. 온디바이스 LoRA 훈련 설정
config = LoRAConfig(
    base_model="./qwen-0.5b.gguf",
    rank=8,
    alpha=16,
    learning_rate=2e-4,
    gradient_accumulation_steps=4
)

# 2. 온디바이스 파인튜닝 루프 실행
with TrainEngine(config) as trainer:
    trainer.load_dataset("./dataset.jsonl")
    print("[Termux-Train] 온디바이스 훈련 루프 시작...")
    for epoch, loss in trainer.train(epochs=3):
        print(f"에포크 {epoch} 완료 - 최종 손실값: {loss:.4f}")
    trainer.save_adapter("./adapters/custom_lora.bin")

3. JavaScript / Node.js 최소 실행 레시피

// Node.js CLI 브리지 실행 예제:
const { execSync } = require('child_process');

console.log('[Termux-Train] 훈련 CLI 실행 중...');
const stdout = execSync('termux-train fine-tune --model ./qwen-0.5b.gguf --data ./dataset.jsonl --rank 8');
console.log(stdout.toString());

5. 하드웨어 장애 대응 및 자동 복구 프로토콜

발생 증상 (에러 로그) 근본 원인 (Root Cause) 엔지니어링 조치 프로토콜
VK_ERROR_DEVICE_LOST Mali Valhall 아키텍처 정수 나눗셈 보폭 0 절삭 무한 루프 발생. --enforce-medium-matmul 옵션으로 워크그룹 크기 128 커널을 강제 바인딩합니다.
VK_ERROR_UNKNOWN (-13) 스냅드래곤 Adreno JIT 컴파일러 레지스터 할당 한도 초과. 특수화 상수 mul_mat_vec_max_cols = 2로 고정하여 안전하게 실행합니다.
배터리 구동 시 지연시간 급증 안드로이드 OS의 배터리 세이버가 CPU 빅코어를 오프라인 전환함. 스레드 친화도(thread_affinity=[4,5,6,7])를 통해 고성능 빅코어에 프로세스를 고정합니다.
프로세스 종료 후 VRAM 미반납 비정상 종료로 인한 POSIX 공유 메모리 핸들 잔류. RAII 소멸자를 호출하거나 shm_unlink()를 통해 좀비 버퍼를 즉시 회수합니다.
