Quickstart & Execution Recipes

Standard usage patterns, neural network training loops, and LoRA recipes

Zero PyTorch Dependency · Pure On-Device Autograd

termux-train runs directly inside Android Termux on smartphone CPUs without requiring heavy C++ virtual environments, CUDA toolchains, or root permissions.

Recipe 1: 5-Line Automatic Differentiation & Gradient Descent

Basic scalar & tensor automatic differentiation graph with analytical backward pass:

import termux_train as tt

# Initialize tensors with gradient tracking
x = tt.tensor([2.0, 3.0], requires_grad=True)
w = tt.tensor([4.0, 5.0], requires_grad=True)
b = tt.tensor(1.0, requires_grad=True)

# Build forward computation graph (DAG)
y = (x * w).sum() + b

# Perform reverse-mode automatic differentiation
y.backward()

print("dL/dx:", x.grad)  # [4.0, 5.0]
print("dL/dw:", w.grad)  # [2.0, 3.0]
print("dL/db:", b.grad)  # 1.0

Recipe 2: End-to-End Neural Network Training with AdamW

Multi-Layer Perceptron (MLP) classification with weight decay and mini-batch gradient updates:

import termux_train as tt
import termux_train.nn as nn
import termux_train.optim as optim

# 1. Define Model Architecture
class MLPClassifier(nn.Module):
    def __init__(self, in_features=8, hidden_dim=32, num_classes=2):
        super().__init__()
        self.fc1 = nn.Linear(in_features, hidden_dim)
        self.norm = nn.RMSNorm(hidden_dim)
        self.act = nn.SiLU()
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        return self.fc2(self.act(self.norm(self.fc1(x))))

# 2. Setup Device, Criterion & Optimizer
model = MLPClassifier(8, 32, 2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

# 3. Training Loop (Simulated 10 Epochs)
x_data = tt.randn(64, 8)
y_labels = tt.randint(0, 2, shape=(64,))

for epoch in range(10):
    optimizer.zero_grad()
    logits = model(x_data)
    loss = criterion(logits, y_labels)
    loss.backward()
    optimizer.step()
    
    print(f"Epoch {epoch+1:02d} | Loss: {loss.item():.6f}")

Recipe 3: RoPE Transformer On-Device Mini-Language Model

Training a Rotary Position Embedding (RoPE) Causal Transformer Block on smartphone RAM:

from termux_train.nn import TransformerBlock, Embedding, Linear
from termux_train.tokenization import ByteTokenizer
import termux_train as tt
import termux_train.optim as optim

# Tokenizer & Hyperparameters
tokenizer = ByteTokenizer()
tokens = tokenizer.encode("The sovereign edge ecosystem trains locally on mobile.")

vocab_size = 256
d_model = 64
n_heads = 4

embed = Embedding(vocab_size, d_model)
block = TransformerBlock(d_model=d_model, n_heads=n_heads, d_ff=128)
head = Linear(d_model, vocab_size)

params = list(embed.parameters()) + list(block.parameters()) + list(head.parameters())
optimizer = optim.AdamW(params, lr=5e-4)

# Forward pass with RoPE attention
input_ids = tt.tensor([tokens[:16]], dtype=tt.int32)
x = embed(input_ids)
h = block(x)
logits = head(h)

print("Output Logits Shape:", logits.shape)  # (1, 16, 256)

Recipe 4: LoRA Fine-Tuning & SafeTensors Weight Export

Applying Low-Rank Adaptation (LoRA) to linear projection layers and exporting adapter weights:

from termux_train.nn import LoRALinear, Linear
from termux_train.runtime import save_safetensors, load_safetensors
import termux_train as tt

# 1. Base Layer
base_layer = Linear(128, 128)

# 2. Inject LoRA Adapter (Rank r=8, Alpha=16.0)
lora_layer = LoRALinear.from_linear(base_layer, r=8, lora_alpha=16.0, lora_dropout=0.05)

# 3. Fine-Tune Adapter (Base weights are frozen)
x = tt.randn(4, 128)
out = lora_layer(x)
loss = out.sum()
loss.backward()

# Verify base weights have zero gradient while LoRA matrices receive gradients
assert lora_layer.weight.grad is None
assert lora_layer.lora_A.grad is not None

# 4. Save Trained LoRA Adapter to SafeTensors
adapter_state = lora_layer.get_adapter_state_dict()
save_safetensors(adapter_state, "adapter_weights.safetensors")
print("LoRA Adapter exported to adapter_weights.safetensors (<50KB)")

Recipe 5: CLI One-Line Training & Checkpoint Management

Executing training tasks directly from the Termux terminal command line:

# Train a mini-transformer on raw text dataset
termux-train train --data dataset.txt --model transformer --d_model 64 --epochs 20 --output checkpoint.safetensors

# Evaluate loss & perplexity on smartphone CPU
termux-train eval --checkpoint checkpoint.safetensors --data test.txt
