버전 아카이브 & 릴리즈 이력 (Changelog)

불변의 릴리즈 내역 및 시맨틱 버저닝 마일스톤 (AMEVA-MCP-Hub)

Release: v3.1.3

v3.1.3 - Seamless Multi-Instance Hub & Port Forwarding

Production Release 2026-10-01
  • Seamless Multi-Instance Port Reuse (Bridge Mode): 11553 포트 점유 시 새 프로세스가 EADDRINUSE로 크래시되지 않고 기존 허브에 자동으로 투명 stdio 브리지 모드로 연결.
  • Dual-Endpoint Proxy Discovery: /api/identity와 루트 / 폴백 탐색을 통해 제로 토큰 환경에서도 100% 인스턴스 자동 판별.
  • Bridge Mode 브라우저 팝업 방어: startBridgeMode 내 noAutoOpen 가드를 강제하여 IDE 백그라운드 구동 시 불필요한 브라우저 창 팝업 원천 차단.
  • WebSocket 핸드셰이크 프로토콜 보강: 제로 토큰 환경에서 auth_response 및 tab_assigned 패킷 라우팅 신뢰성 확보.
  • 프론트엔드 재연결 지수 백오프: 서버 재시작 시 콘솔 로그 폭주를 방지하는 최대 15초 지수 백오프 적용.

v3.1.2 - Seamless IDE Integration, Zero-Token Mode & Fleet Testing

Production Release 2026-09-29
  • Zero-Token Local Execution Mode: 로컬 루프백 인터페이스 접속 시 불필요한 보안 토큰 요구 해제.
  • On-Device Tester Fleet Adapter 통합: tester_probe_fleet, tester_get_devices, tester_inspect_device, tester_run_benchmark, tester_remote_fs, tester_kill_process, tester_purge_device 7대 도구 탑재.
  • Silent Background Daemon Mode: IDE stdio 파이프 구동 시 브라우저 자동 실행을 차단하고 50ms 미만 초고속 부팅 보장.
  • Node.js 24 ESM 호환성: fileURLToPath를 통한 모듈 경로 해석 표준화.

v3.0.0 - Universal Polyglot WASM Hub Master Release

Major Milestone 2026-08-26
  • 단일 Node.js 프로세스 인메모리 WASI 실행 엔진 최초 릴리즈.
  • GitHub 멀티 리포지토리 동적 도구 구독 및 실시간 동기화.
  • 1536차원 AI 벡터 코사인 유사도 연산 및 Top-K RAG 검색 엔진 탑재.
