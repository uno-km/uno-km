AMEVA-MCP-Hub

Zero-Install Universal Polyglot WASM & AI Vector Model Context Protocol Hub

1-Line Quick Installation

Install the official package directly into your runtime:

npx ameva-mcp-hub
# or as SDK:
npm install ameva-mcp-hub

The Engineering Challenge

Traditional MCP server setups require heavy local compilers (JDK, Rust, Clang, Python venvs) and multiple background daemons for each repository, causing massive memory overhead and frequent dependency conflicts across client platforms.

The Architectural Breakthrough

Executes multi-language open-source tools (C++, Rust, Java, Python, Go) in-memory via WASI WebAssembly inside a single Node.js process with dynamic multi-repo subscriptions, real-time AI tool propagation, and heuristic route dispatching.

Key Capabilities & Built-in Hardening

Zero-Toolchain Polyglot WASM Engine

Executes C++, Rust, Java (TeaVM), and Go binaries in memory with zero local compiler requirements.

Dynamic Multi-Repository Subscription

Subscribe to multiple GitHub tool repositories on the fly with real-time notifications/tools/list_changed propagation.

AI Vector & Semantic Ranking Engine

High-dimensional Cosine Similarity and in-memory Top-K semantic search for local RAG pipelines.

Heuristic Adaptive Route Dispatcher

Automatically probes host environment and task risk to route execution between HOST_NATIVE and WASM_SANDBOX.

Zero-Browser Pure Node.js Architecture

450ms cold boot and 30MB low memory footprint completely eliminating browser/Puppeteer background windows.

Dual-Purpose CLI & Embeddable SDK

Usable as a standalone MCP server via npx or as an isolated execution engine inside custom JS/TS backends.

Canonical Usage Example

# Connect Claude Desktop / Cursor via npx:
# { "mcpServers": { "hub": { "command": "npx", "args": ["-y", "ameva-mcp-hub"] } } }

import { WasiRunner, NodeExecutor, heuristicRouter } from "ameva-mcp-hub";

// Execute C++/Rust/Java WASM in memory
const runner = new WasiRunner({ args: ["1234", "5678"] });
const result = await runner.run(wasmBuffer);
console.log("Result:", result.stdout);

// Compute AI Cosine Similarity
const executor = new NodeExecutor();
const sim = await executor.executeTool("vector_cosine_similarity", {
  vecA: [0.8, 0.6, 0.0],
  vecB: [0.79, 0.61, 0.05]
});
console.log("Similarity:", sim.content[0].text);
