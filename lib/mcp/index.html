소개 및 아키텍처 개요

온디바이스 자율 에이전트를 위한 분산 MCP 도구 게이트웨이 및 샌드박스 라우터

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# Node.js 공식 패키지 매니저
npm install ameva-mcp-hub

기술적 당면 과제

AI 에이전트가 로컬 도구를 호출할 때 무거운 외부 클라우드 중계기를 거쳐야 하고, 악의적인 명령어나 셸 인젝션으로 인해 로컬 시스템이 파괴될 수 있는 보안 위협이 존재했습니다.

아키텍처 혁신 및 기술 돌파구

표준 JSON-RPC 2.0 stdio 및 SSE 트랜스포트를 지원하는 온디바이스 MCP 라우터를 구축하고 엄격한 시스템 콜 샌드박스를 적용하여 안전하고 빠른 로컬 도구 호출을 지원합니다.

핵심 가치 제안 (Why It Matters)

명령어 한 줄로 AI 에이전트들을 위한 만능 도구 상자가 열립니다. 터미널 환경에서도 다양한 도구를 스마트하게 연결합니다.

주요 기능 및 하드웨어 강화

JSON-RPC 2.0 표준 stdio/SSE 완벽 준수

앤트로픽 MCP 표준 프로토콜을 온디바이스 환경에서 100% 호환되도록 구현했습니다.

엄격한 프로세스 격리 샌드박스

도구 실행 시 권한을 엄격히 제한하여 호스트 파일 시스템의 무단 변경을 차단합니다.

멀티 에이전트 동시 라우팅

다수의 AI 에이전트가 동시에 도구를 호출해도 충돌 없이 큐잉 처리합니다.

제로 외부 서버 종속성

인터넷이 끊긴 오프라인 비행기 모드에서도 완벽하게 로컬 도구들을 실행합니다.

동적 도구 자동 발견(Discovery)

새로운 도구가 추가되면 즉시 스키마를 읽어 AI에게 사용법을 브로드캐스팅합니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
Stdio Pipe Serializer 표준 입출력을 통한 초고속 바이너리/텍스트 JSON 프레임 전송 프로덕션 안정
SSE Event Broadcaster 웹 클라이언트 실시간 상태 스트리밍 파이프라인 프로덕션 안정
Sandbox Seccomp Filter 위험 시스템 콜 차단 커널 보안 계층 프로덕션 안정
Tool Schema Registry 도구 시그니처 및 타입 무결성 검증 엔진 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

# 파이썬 MCP Stdio 클라이언트 예제
import json, subprocess

proc = subprocess.Popen(["npx", "ameva-mcp-hub", "--stdio"], stdin=subprocess.PIPE, stdout=subprocess.PIPE, text=True)
req = {"jsonrpc": "2.0", "id": 1, "method": "tools/list", "params": {}}
proc.stdin.write(json.dumps(req) + "\n")
proc.stdin.flush()
res = json.loads(proc.stdout.readline())
print("[MCP 도구 목록]:", [t["name"] for t in res["result"]["tools"]])

Node.js (npm) 사용 예제

const { McpHubServer, StdioTransport } = require('ameva-mcp-hub');

async function main() {
  const hub = new McpHubServer({ name: 'TermuxLocalHub', version: '3.0.1' });
  hub.registerTool('calc_hash', async (args) => ({ hash: Buffer.from(args.text).toString('base64') }));
  await hub.connect(new StdioTransport());
  console.log('[MCP Hub] 로컬 표준 입출력 수신 대기 중...');
}

main();
