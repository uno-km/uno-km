설치 및 환경 구성 가이드

WASI 인메모리 런타임, npx 무설치 실행 및 IDE stdio 브리지 구성 (AMEVA-MCP-Hub)

Release: v3.1.3
핵심 가치 제안 (Why It Matters)

호스트 환경에 C++, Rust, Python 등 개별 언어 컴파일러를 설치할 필요 없이, 단일 Node.js 프로세스 메모리 상에서 WASI 바이트코드를 즉시 실행하는 제로 오염 유니버설 MCP 허브입니다.

1. 1줄 즉시 실행 및 패키지 설치

# 설치 없이 1줄로 즉시 MCP 허브 데몬 기동
npx ameva-mcp-hub

# Node.js 프로젝트 SDK 종속성 설치
npm install ameva-mcp-hub

# Python 클라이언트 SDK 설치
pip install ameva-mcp-hub

2. IDE 연동 가이드 (Claude Desktop / Cursor / Antigravity)

에이전트 IDE 환경의 claude_desktop_config.json 또는 MCP 설정 파일에 아래 구성을 추가합니다:

{
  "mcpServers": {
    "ameva-mcp-hub": {
      "command": "npx",
      "args": ["-y", "ameva-mcp-hub", "--headless"]
    }
  }
}

이미 11553 포트에서 허브가 실행 중인 경우, 새로 생성된 IDE stdio 프로세스는 자동으로 투명 브리지 모드(Bridge Mode)로 전환되어 포트 충돌 없이 단일 인스턴스에 즉각 직결됩니다.
