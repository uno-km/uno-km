퀵스타트 및 실행 레시피

Python, TypeScript 및 CLI 도구 즉시 호출 표준 코드 (AMEVA-MCP-Hub)

Release: v3.1.3
핵심 가치 제안 (Why It Matters)

인메모리 WASI 샌드박스를 통해 단 1ms 미만의 지연시간으로 수십 개의 다국어 AI 도구를 안전하게 실행합니다.

1. Node.js / TypeScript SDK 레시피

import { MCPHub, MCPClient } from 'ameva-mcp-hub';

// 1. 인메모리 허브 서버 기동 (기본 포트: 11553)
const hub = new MCPHub({ port: 11553, requireToken: false });
await hub.start();

// 2. 클라이언트 연결 및 WASI 도구 실행
const client = new MCPClient({ port: 11553 });
const result = await client.callTool('calc', { expression: '1024 * 768' });
console.log(`[WASI 도구 실행 결과]:`, result);

2. Python 클라이언트 SDK 레시피

import asyncio
from ameva_mcp_hub import MCPClient

async def main():
    # 실행 중인 MCP 허브에 비동기 연결
    client = MCPClient(port=11553)
    
    # 1. 사용 가능한 도구 목록 조회
    tools = await client.list_tools()
    print(f"등록된 도구 개수: {len(tools)}")
    
    # 2. WASI 기반 계산기 및 텍스트 변환 도구 호출
    res = await client.call_tool("calc", {"expression": "2 ** 16"})
    print(f"도구 반환값: {res}")

asyncio.run(main())
