소개 및 아키텍처 개요

Whisper.cpp, Vosk, Sherpa 3중 엔진 및 128차원 X-Vector 화자 분리 탑재 100% 로컬 음성 인식 SDK

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install termux-stt

# Node.js 공식 패키지 매니저
npm install termux-stt

기술적 당면 과제

상용 클라우드 음성 인식 서비스는 사적인 대화와 음성 데이터가 빅테크 서버로 유출될 심각한 보안 위험이 있습니다. 반면 모바일 기기에서 Whisper.cpp나 Vosk를 직접 빌드하려면 FFmpeg Bionic 링커 충돌, 2GB 이상의 파이토치 의존성으로 인해 앱 구동이 불가능합니다.

아키텍처 혁신 및 기술 돌파구

외부 네트워크 전송 0%의 완전 로컬 프라이버시 환경에서 Whisper.cpp, Vosk, Sherpa-ONNX 3중 엔진과 순수 파이썬 128차원 X-Vector 화자 분리를 단일 패키지로 통합하여, 80MB 초경량 메모리로 고정밀 전사(Transcription)를 지원합니다.

핵심 가치 제안 (Why It Matters)

빅테크 기업 서버에 내 목소리가 넘어갈까 불안하셨나요? 외부 유출 걱정 0%, 복잡한 프로그램 설치 걱정 0%. 단말기 안에서 비밀스럽고 안전하게, 누가 말했는지까지 똑똑하게 적어드립니다.

주요 기능 및 하드웨어 강화

외부 유출 0% 오디오 프라이버시

음성 캡처, 음향 특징 추출, 텍스트 전사가 100% 로컬 기기 내에서만 실행되어 외부 네트워크로의 데이터 누출이 원천 차단됩니다.

3중 STT 엔진 통합 팩토리

단일 create_engine() 팩토리 인터페이스를 통해 Whisper.cpp(정밀도), Vosk(지연시간), Sherpa-ONNX를 자유롭게 전환합니다.

순수 파이썬 128차원 화자 분리

PyTorch나 Scikit-Learn 없이 Vosk X-Vector 임베딩 기반의 순수 파이썬 K-Means 클러스터링으로 다중 화자를 정밀 분리합니다.

제로 서브프로세스 고속 오디오 파서

외부 FFmpeg 프로세스 호출을 우회하는 내장 순수 파이썬 WAV 파서를 탑재하여 Bionic 링커 오류를 제거했습니다.

워커 프로세스 풀 크래시 격리

네이티브 C++ 엔진을 격리된 워커 프로세스 풀에서 관리하여 네이티브 세그멘테이션 오류로부터 메인 앱을 안전하게 보호합니다.

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from termux_stt import create_engine

# 1. 100% 로컬 STT 엔진 초기화
engine = create_engine(engine_type="whisper", model_name="tiny")

# 2. 오디오 파일 텍스트 전사 및 화자 분리
result = engine.transcribe("samples/jfk_1min.wav", diarize=True)
print(f"[전사 결과]: {result.text}")
for segment in result.segments:
    print(f"[{segment.speaker}] {segment.start:.2f}s ~ {segment.end:.2f}s: {segment.text}")

Node.js (npm) 사용 예제

const { STTEngine } = require('termux-stt');

async function main() {
  const engine = new STTEngine({ model: 'tiny', language: 'en' });
  const result = await engine.transcribeFile('samples/jfk_1min.wav');
  console.log(`[전사 결과]: ${result.text}`);
}

main();
