Quickstart & Execution Recipes

Standard usage patterns and rapid prototyping code

Included 60.00s JFK Sample Audio

termux-stt packages John F. Kennedy's 1961 Inaugural Address (samples/jfk_1min.wav, 16kHz Mono PCM) for instant out-of-the-box verification!

Recipe 1: 1-Line Subtitle Transcription (SRT / WebVTT / JSON)

# 1. Transcribe audio and export to synchronized SRT subtitles
termux-stt transcribe samples/jfk_1min.wav --format srt > subtitles.srt

# 2. Export directly to WebVTT for HTML5 video players
termux-stt transcribe samples/jfk_1min.wav --format vtt > subtitles.vtt

# 3. Export to structured JSON for data pipelines
termux-stt transcribe samples/jfk_1min.wav --format json > output.json

Recipe 2: 128d Speaker Diarization ("Who Spoke When?")

Run high-precision 2-speaker diarization using pure Python K-Means clustering without PyTorch:

termux-stt diarize samples/jfk_1min.wav --speakers 2 --format text

Sample Output:

[Speaker 0] Vice President Johnson, Mr. Speaker, Mr. Chief Justice, President Eisenhower...
[Speaker 0] Nixon, President Truman, Reverend clergy, fellow citizens...
[Speaker 1] We observe today not a victory of party, but a celebration of freedom...

Recipe 3: Real-Time Microphone Streaming

Speak directly into your smartphone microphone with low latency and real-time Silero-VAD silence filtering:

# CLI real-time listener (Press Ctrl+C to terminate)
termux-stt listen --engine whisper --model tiny --lang ko

Recipe 4: High-Precision Domain Prompting & Translation

# Provide context prompt hints for specialized medical/technical vocabularies and translate to English
termux-stt transcribe meeting.wav \
  --model small \
  --prompt "AMEVA-Forge, WebGPU, ARM NEON, Bionic libc" \
  --translate \
  --format srt

Recipe 5: Programmatic Python SDK Integration

from termux_stt import create_engine

# 1. Initialize Engine with optimal threads
engine = create_engine("whisper", model="base", lang="en", threads=4)

# 2. Transcribe Audio
result = engine.transcribe("samples/jfk_1min.wav")

print("Full Transcript:", result.text)
print(f"Detected Duration: {result.duration:.2f}s")
print("SRT Block:\n", result.to_srt())

Recipe 6: Programmatic Node.js / TypeScript API

const { createEngine } = require("termux-stt");

async function transcribeAudio() {
  const engine = createEngine("whisper", { model: "tiny", lang: "en", threads: 4 });
  const result = await engine.transcribe("samples/jfk_1min.wav");
  
  console.log("Total Segments:", result.segments.length);
  console.log("SRT Output:\n", result.toSrt());
}
transcribeAudio();
