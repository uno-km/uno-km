퀵스타트 및 실행 레시피

즉시 실행 가능한 1줄 CLI 명령어, 최소 코드 레시피 및 하드웨어 검증 모델 프로파일 (Termux-STT)

핵심 가치 제안 (Why It Matters)

스마트폰 마이크에 대고 말하기만 하면 끝. 귀찮은 변환 작업 없이 내 목소리가 즉시 정확한 텍스트로 화면에 나타납니다.

1. 1줄 CLI 즉시 실행

기본값이 사전 구성되어 있어 별도 설정 없이 바로 실행할 수 있습니다:

termux-stt transcribe samples/jfk_1min.wav --model tiny --language en

2. Python 최소 실행 레시피

from termux_stt import create_engine

# 1. 100% 로컬 STT 엔진 초기화
engine = create_engine(engine_type="whisper", model_name="tiny")

# 2. 오디오 파일 텍스트 전사 및 화자 분리
result = engine.transcribe("samples/jfk_1min.wav", diarize=True)
print(f"[전사 결과]: {result.text}")
for segment in result.segments:
    print(f"[{segment.speaker}] {segment.start:.2f}s ~ {segment.end:.2f}s: {segment.text}")

3. JavaScript / Node.js 최소 실행 레시피

const { STTEngine } = require('termux-stt');

async function main() {
  const engine = new STTEngine({ model: 'tiny', language: 'en' });
  const result = await engine.transcribeFile('samples/jfk_1min.wav');
  console.log(`[전사 결과]: ${result.text}`);
}

main();

5. 하드웨어 장애 대응 및 자동 복구 프로토콜

발생 증상 (에러 로그) 근본 원인 (Root Cause) 엔지니어링 조치 프로토콜
VK_ERROR_DEVICE_LOST Mali Valhall 아키텍처 정수 나눗셈 보폭 0 절삭 무한 루프 발생. --enforce-medium-matmul 옵션으로 워크그룹 크기 128 커널을 강제 바인딩합니다.
VK_ERROR_UNKNOWN (-13) 스냅드래곤 Adreno JIT 컴파일러 레지스터 할당 한도 초과. 특수화 상수 mul_mat_vec_max_cols = 2로 고정하여 안전하게 실행합니다.
배터리 구동 시 지연시간 급증 안드로이드 OS의 배터리 세이버가 CPU 빅코어를 오프라인 전환함. 스레드 친화도(thread_affinity=[4,5,6,7])를 통해 고성능 빅코어에 프로세스를 고정합니다.
프로세스 종료 후 VRAM 미반납 비정상 종료로 인한 POSIX 공유 메모리 핸들 잔류. RAII 소멸자를 호출하거나 shm_unlink()를 통해 좀비 버퍼를 즉시 회수합니다.
