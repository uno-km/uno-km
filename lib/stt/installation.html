Installation & Setup Guide

Hardware acceleration, Termux setup, and dependency management

1-Click Self-Contained Automated Installation

termux-stt includes an automated self-contained installer that provisions all native dependencies, compiles ARM NEON C++ binaries, and verifies hardware vector extensions in a single command.

1. Automated Package Installation

Python Edition (PyPI):

# 1. Install official PyPI package
pip install --upgrade termux-stt

# 2. 1-Click native compiler and dependency provisioning
termux-stt install

Node.js / TypeScript Edition (npm):

# 1. Install official global npm package
npm install -g termux-stt

# 2. 1-Click native setup
termux-stt install

2. Android Termux Prerequisites & System Dependencies

If you are provisioning a clean Android Termux environment from scratch, execute the following system package installations:

# Update Termux repository index and install native toolchain
pkg update -y && pkg install -y \
  python \
  nodejs-lts \
  ffmpeg \
  libbluray \
  libxml2 \
  cmake \
  make \
  clang \
  git \
  termux-api

3. Self-Healing Diagnostic Health Check

Verify that your system environment, audio linkers, and ARM NEON binaries are fully functional:

termux-stt doctor

Expected Terminal Output:

System Environment Check:
-----------------------------------
OS: Android (aarch64)
✅ [OK] ffmpeg is installed
✅ [OK] whisper.cpp engine found
✅ [OK] Python 3.13.x
-----------------------------------
Doctor check complete.

4. Air-Gapped / Offline Deployment

For strictly air-gapped devices without internet access, pre-seed GGML models into the local cache directory:

# Cache directory structure
mkdir -p ~/.cache/termux-stt/models/whisper
cp ggml-tiny.bin ~/.cache/termux-stt/models/whisper/
cp ggml-small.bin ~/.cache/termux-stt/models/whisper/
