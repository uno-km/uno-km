소개 및 아키텍처 개요

의존성 없는 모바일 에이전트 DAG 워크플로우 오케스트레이션 및 스트리밍 파이프라인

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install termux-aichain

# Node.js 공식 패키지 매니저
npm install termux-aichain

기술적 당면 과제

음성 인식(STT), 두뇌(LLM), 음성 합성(TTS), 시각(Vision) 모델을 서로 연결할 때 파이프라인 지연 시간이 누적되고 중간 데이터 복사로 인해 메모리 오버플로우가 발생합니다.

아키텍처 혁신 및 기술 돌파구

순수 파이썬/C++ 무의존성 비동기 DAG 실행 엔진과 POSIX 공유 메모리 링 버퍼를 통해 노드 간 제로카피 스트리밍 파이프라인을 구축하여 전 구간 지연시간을 400ms 미만으로 단축했습니다.

핵심 가치 제안 (Why It Matters)

무거운 클라우드 프레임워크 없이 스마트폰 안에서 음성 인식, 인공지능 두뇌, 음성 출력을 하나의 흐름으로 엮어냅니다.

주요 기능 및 하드웨어 강화

순수 파이썬/C++ 제로 의존성 DAG 코어

LangChain 등 거대 라이브러리 없이 순수 위상 정렬 알고리즘으로 노드를 스케줄링합니다.

POSIX 공유 메모리 제로카피 스트리밍

노드 간 대용량 오디오/비디오 프레임을 메모리 복사 없이 포인터 전달로 즉각 스트리밍합니다.

비동기 스트리밍 이벤트 파이프라인

이전 노드의 생성이 완전히 끝나기 전에 첫 토큰부터 즉시 다음 노드로 흘려보냅니다.

단일 노드 실패 격리 및 자동 롤백

특정 도구 실행 실패 시 전체 시스템 중단 없이 안전하게 대체 노드로 복구합니다.

초경량 저전력 모바일 배터리 세이프

CPU 사용량을 엄격히 모니터링하여 스마트폰 발열을 최소화합니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
DAG Topological Scheduler 의존성 그래프 기반 비동기 동시성 태스크 스케줄러 프로덕션 안정
Lockless IPC Ring Buffer POSIX shm_open 기반 제로카피 오디오/토큰 스트림 프로덕션 안정
Streaming Event Emitter 발생 즉시 하류 노드로 전달하는 논블로킹 이벤트 큐 프로덕션 안정
Fail-Fast Watchdog 시간 초과 및 크래시 감지 즉시 안전 회수 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from termux_aichain import DAGPipeline, Node

# 1. 온디바이스 보이스 에이전트 DAG 생성
pipeline = DAGPipeline("VoiceAssistant")
stt_node = Node(name="stt", task="termux_stt.transcribe", shm_output=True)
llm_node = Node(name="llm", task="termux_bitnet.generate", depends_on=["stt"])
tts_node = Node(name="tts", task="termux_tts.synthesize", depends_on=["llm"])

pipeline.add_nodes([stt_node, llm_node, tts_node])
results = pipeline.execute({"audio_input": "sample.wav"})
print(f"[AIChain] 전 구간 E2E 지연시간: {results.total_latency_ms:.1f} ms")

Node.js (npm) 사용 예제

const { DAGPipeline } = require('termux-aichain');

async function main() {
  const dag = new DAGPipeline('VoiceBot');
  dag.addNode({ id: 'stt', task: 'termux-stt:listen' });
  dag.addNode({ id: 'llm', task: 'termux-bitnet:chat', dependsOn: ['stt'] });
  dag.addNode({ id: 'tts', task: 'termux-tts:speak', dependsOn: ['llm'] });

  const stream = await dag.executeStream({ audioFile: 'sample.wav' });
  stream.on('finish', (metrics) => console.log(`[AIChain] 실행 완료 소요시간: ${metrics.durationMs} ms`));
}

main();
