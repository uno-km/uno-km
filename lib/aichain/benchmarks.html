하드웨어 벤치마크 & 오케스트레이션 메트릭

삼성 갤럭시 실기기 기반 Zero-Dependency DAG 에이전트 체이닝 실측치 (Termux-AIChain)

핵심 가치 제안 (Why It Matters)

외부 무거운 파이썬 프레임워크(LangChain 등) 없이 순수 내장 FSM으로 STT, LLM, TTS, 비전 모듈을 연결할 때의 노드 디스패치 지연시간(마이크로초)과 초경량 메모리 실측치입니다.

1. 단말기 칩셋별 단일 노드 및 멀티-에이전트 DAG 파이프라인 지연시간

테스트 단말기 SoC 및 CPU 아키텍처 단일 노드 디스패치 3-Node 풀 파이프라인 (STT→LLM→TTS) 프로세스 RSS 메모리 외부 라이브러리 의존성
삼성 갤럭시 S25 스냅드래곤 8 Elite (Oryon x8 코어) 0.08 ms (82 μs) 0.32 ms 8.5 MB 0개 (Zero-Dependency)
삼성 갤럭시 S21 엑시노스 2100 (Cortex-X1 + A78 x3) 0.18 ms (185 μs) 0.74 ms 9.2 MB 0개 (Zero-Dependency)
삼성 갤럭시 S20 스냅드래곤 865 (Kryo 585 x8) 0.22 ms (224 μs) 0.88 ms 9.0 MB 0개 (Zero-Dependency)
삼성 갤럭시 A35 엑시노스 1380 (Cortex-A78 x4) 0.35 ms (352 μs) 1.25 ms 8.8 MB 0개 (Zero-Dependency)

2. 메모리 점유 및 파이프라인 처리량 비교

프레임워크 스택 구동 아키텍처 초기 웜업 메모리 100,000회 연속 디스패치 시 누수 콜드 스타트 기동 시간
Termux-AIChain (본 엔진) Pure Python / TS Deterministic FSM 8.5 MB ~ 9.2 MB 0 바이트 (안정) 0.012초 (12 ms)
레거시 에이전트 프레임워크 LangChain / LlamaIndex 등 거대 의존성 145 MB ~ 220 MB 가비지 컬렉터 스파이크 빈발 2.84초 ~ 4.20초

3. 벤치마크 재현 가이드

결정론적 유한 상태 머신 (FSM)

모든 노드 전이와 예외 처리를 엄격한 상태 다이어그램으로 사전 검증하여 예기치 않은 루프나 교착 상태(Deadlock)를 원천 방지합니다.

서브 밀리초 텐서 데이터 마샬링

노드 간 데이터를 직렬화/역직렬화 오버헤드 없이 인메모리 버퍼로 직접 전달하여 찰나의 지연시간을 실현합니다.
