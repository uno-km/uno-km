소개 및 아키텍처 개요

루팅/PRoot 없는 안드로이드 네이티브 Stable Diffusion 이미지 생성 및 삼성 갤러리 자동 인덱싱 엔진

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install termux-diffusion

# Node.js 공식 패키지 매니저
npm install termux-diffusion

기술적 당면 과제

모바일에서 이미지 생성을 시도할 때 외부 클라우드의 데이터 검열과 비싼 월 구독료가 발생하며, 스마트폰에서 직접 구동할 경우 무거운 PRoot 리눅스 컨테이너와 심각한 메모리 초과(OOM) 크래시가 단말기를 다운시킵니다.

아키텍처 혁신 및 기술 돌파구

루팅이나 PRoot 가상화 환경 없이 안드로이드 Bionic C++에 직접 컴파일된 최적화 연산 엔진을 구축하여, 메모리 누수 없이 단말기 자체에서 프라이빗 이미지를 생성하고 삼성 갤러리에 즉시 자동 색인합니다.

핵심 가치 제안 (Why It Matters)

내가 상상한 그림을 남의 서버 눈치 보지 않고, 비싼 구독료 없이 내 폰에서 마음껏 그려보세요. 복잡한 컴퓨터 지식 없이도 터미널 한 번 톡 치면, 스마트폰 기본 갤러리에 내가 만든 작품이 바로 쏙 들어옵니다.

주요 기능 및 하드웨어 강화

루팅/PRoot 없는 100% 네이티브 구동

안드로이드 Bionic libc 직접 바인딩으로 PRoot 가상화 오버헤드와 파일 권한 충돌을 원천 박멸했습니다.

삼성 갤러리 즉시 자동 인덱싱

생성된 이미지를 MediaStore 인덱서와 연동하여 파일 탐색기를 열 필요 없이 스마트폰 갤러리에 즉시 표시합니다.

ARMv8.2-A DotProd/FP16 벡터 연산

Cortex-A78 빅코어 전용 SIMD 벡터 명령어를 활용하여 과도한 전력 소모 없이 노이즈 제거 연산을 가속합니다.

엄격한 OOM 방지 메모리 스왑 가드

단말기 DRAM 가용량을 실시간 감시하여 OOM 킬러 발동 전 안전하게 텐서를 관리합니다.

원클릭 pip 및 npm 통합 배포

복잡한 깃 클론이나 파이토치 설치 없이 패키지 매니저로 즉시 설치하고 CLI와 SDK로 즉시 생성합니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
UNet Cross-Attention Engine ARM NEON FP16 벡터화 텐서 곱셈 및 공간 어텐션 프로덕션 안정
CLIP Text Encoder 프롬프트 텍스트 토크나이징 및 잠재 벡터 임베딩 맵핑 프로덕션 안정
VAE Latent Decoder 잠재 공간(Latent Space) 텐서를 512x512 RGB 비트맵으로 디코딩 프로덕션 안정
MediaStore Broadcast Hook 안드로이드 미디어 스캐너 브로드캐스트 자동 전송 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from termux_diffusion import DiffusionPipeline

# 1. 온디바이스 디퓨전 파이프라인 초기화
pipe = DiffusionPipeline.from_pretrained("sd-1.5-quant")

# 2. 텍스트 프롬프트 기반 이미지 생성
print("[Diffusion] 이미지 생성 연산 중 (약 60초 소요)...")
image = pipe.generate(
    prompt="a serene cybernetic garden on mars, 8k resolution",
    steps=20,
    guidance_scale=7.5,
    sync_gallery=True
)
image.save("cyber_garden.png")
print("[완료] 생성이 완료되어 삼성 갤러리에 자동 등록되었습니다.")

Node.js (npm) 사용 예제

const { DiffusionPipeline } = require('termux-diffusion');

async function main() {
  const pipe = new DiffusionPipeline({ model: 'sd-1.5-quant' });
  const imgPath = await pipe.generate({
    prompt: 'a serene cybernetic garden on mars, 8k resolution',
    steps: 20
  });
  console.log(`[생성 완료]: ${imgPath}`);
}

main();
