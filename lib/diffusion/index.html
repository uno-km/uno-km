Termux-Diffusion

Non-Root On-Device Stable Diffusion Image Generation Framework for Android Termux

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-diffusion
# or:
npm install termux-diffusion

The Engineering Challenge

Running heavy image generation models usually requires cloud GPUs or rooted mobile environments with custom Linux kernels.

The Architectural Breakthrough

Compiles C++ NEON kernels directly to Android Bionic libc, running Stable Diffusion v1.5 / Turbo entirely locally within 4GB RAM.

Key Capabilities & Built-in Hardening

Deterministic 0-Drift Output

Bit-exact floating-point precision verified across heterogeneous ARM64 & WebGPU hardware.

Zero Cloud Egress Architecture

Operates 100% on the local client without external network telemetry leaks.

Memory Leakage Protection

Weakref lifetime management preventing GPU VRAM / system RAM leaks.

Canonical Usage Example

import termux_diffusion as td

pipe = td.DiffusionPipeline.from_pretrained("sd-turbo-arm64")
image = pipe.generate("A cinematic futuristic laboratory in Seoul", steps=4)
image.save("output.png")
import { DiffusionPipeline } from "termux-diffusion";

const pipe = await DiffusionPipeline.load("sd-turbo-arm64");
const imgBuffer = await pipe.generate("A high-tech cyberpunk workstation", { steps: 4 });
