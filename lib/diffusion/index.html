Termux-Diffusion

Pure CPU Native On-Device Stable Diffusion Runtime for Android Termux

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-diffusion && termux-diffusion install
# or:
npm install termux-diffusion && npx termux-diffusion install

The Engineering Challenge

Generating AI images on mobile devices typically requires cloud API dependencies or heavy virtualized container layers (PRoot) that quickly exceed RAM limits.

The Architectural Breakthrough

Executes quantized Stable Diffusion models with ARMv8.2-A DotProd/FP16 NEON SIMD vector instructions, VAE tiling, and direct Android MediaStore synchronization.

Key Capabilities & Built-in Hardening

Zero-PRoot Native ARM64 Bionic

Executes directly without root permissions, virtual machines, or PRoot Linux overhead.

One-Touch Pure CPU Native Engine

Provisions precompiled ARM64 CPU native binary and OpenMP runtime in seconds without thermal compilation overhead.

Android MediaStore Auto-Indexing

Automatically synchronizes generated images into Pictures/TermuxDiffusion and registers with Android MediaStore.

Supported Compute Kernels & Operations

Canonical Usage Example

import termux_diffusion as td

# 1. Generate image using pure CPU on Android hardware
image_path = td.generate(
    prompt="cute dolphin, high quality illustration",
    model="anime",
    steps=6,
    device="cpu"
)
print(f"Generated and saved to Gallery: {image_path}")

import { generate } from "termux-diffusion";

const result = await generate({
  prompt: "cute polar bear, high quality illustration",
  model: "anime",
  steps: 6,
  device: "cpu"
});
console.log("Image created:", result.outputPath);
