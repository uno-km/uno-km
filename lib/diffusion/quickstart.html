퀵스타트 및 실행 레시피

즉시 실행 가능한 1줄 CLI 명령어, 최소 코드 레시피 및 하드웨어 검증 모델 프로파일 (Termux-Diffusion)

핵심 가치 제안 (Why It Matters)

원하는 그림의 설명을 한 줄 적기만 하면, 스마트폰이 스스로 붓을 들어 아름다운 작품을 그려냅니다.

1. 1줄 CLI 즉시 실행

기본값이 사전 구성되어 있어 별도 설정 없이 바로 실행할 수 있습니다:

termux-diffusion generate --prompt 'a serene cybernetic garden on mars, 8k resolution' --steps 20

2. Python 최소 실행 레시피

from termux_diffusion import DiffusionPipeline

# 1. 온디바이스 디퓨전 파이프라인 초기화
pipe = DiffusionPipeline.from_pretrained("sd-1.5-quant")

# 2. 텍스트 프롬프트 기반 이미지 생성
print("[Diffusion] 이미지 생성 연산 중 (약 60초 소요)...")
image = pipe.generate(
    prompt="a serene cybernetic garden on mars, 8k resolution",
    steps=20,
    guidance_scale=7.5,
    sync_gallery=True
)
image.save("cyber_garden.png")
print("[완료] 생성이 완료되어 삼성 갤러리에 자동 등록되었습니다.")

3. JavaScript / Node.js 최소 실행 레시피

const { DiffusionPipeline } = require('termux-diffusion');

async function main() {
  const pipe = new DiffusionPipeline({ model: 'sd-1.5-quant' });
  const imgPath = await pipe.generate({
    prompt: 'a serene cybernetic garden on mars, 8k resolution',
    steps: 20
  });
  console.log(`[생성 완료]: ${imgPath}`);
}

main();

5. 하드웨어 장애 대응 및 자동 복구 프로토콜

발생 증상 (에러 로그) 근본 원인 (Root Cause) 엔지니어링 조치 프로토콜
VK_ERROR_DEVICE_LOST Mali Valhall 아키텍처 정수 나눗셈 보폭 0 절삭 무한 루프 발생. --enforce-medium-matmul 옵션으로 워크그룹 크기 128 커널을 강제 바인딩합니다.
VK_ERROR_UNKNOWN (-13) 스냅드래곤 Adreno JIT 컴파일러 레지스터 할당 한도 초과. 특수화 상수 mul_mat_vec_max_cols = 2로 고정하여 안전하게 실행합니다.
배터리 구동 시 지연시간 급증 안드로이드 OS의 배터리 세이버가 CPU 빅코어를 오프라인 전환함. 스레드 친화도(thread_affinity=[4,5,6,7])를 통해 고성능 빅코어에 프로세스를 고정합니다.
프로세스 종료 후 VRAM 미반납 비정상 종료로 인한 POSIX 공유 메모리 핸들 잔류. RAII 소멸자를 호출하거나 shm_unlink()를 통해 좀비 버퍼를 즉시 회수합니다.
