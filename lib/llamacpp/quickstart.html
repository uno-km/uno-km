퀵스타트 및 실행 레시피

즉시 실행 가능한 1줄 CLI 명령어, 최소 코드 레시피 및 하드웨어 검증 모델 프로파일 (Termux-LlamaCpp)

핵심 가치 제안 (Why It Matters)

명령어 한 줄만 입력하면 스마트폰 안에서 최첨단 인공지능과 실시간으로 대화를 시작할 수 있습니다.

1. 1줄 CLI 즉시 실행

기본값이 사전 구성되어 있어 별도 설정 없이 바로 실행할 수 있습니다:

termux-llamacpp chat --model qwen2.5-0.5b --ngl 99 --prompt '양자 컴퓨팅을 쉽게 설명해줘'

2. Python 최소 실행 레시피

from termux_llamacpp import LlamaEngine

# 1. 100% GPU 오프로딩 엔진 초기화
engine = LlamaEngine(
    model_path="~/.cache/termux-llamacpp/models/qwen2.5-0.5b-q4_k_m.gguf",
    n_gpu_layers=99,
    ctx_size=2048
)

# 2. 대화 스트리밍 생성
print("[질문]: 양자 컴퓨팅을 쉽게 설명해줘")
for token in engine.stream_chat("양자 컴퓨팅을 쉽게 설명해줘:"):
    print(token, end="", flush=True)
print()

3. JavaScript / Node.js 최소 실행 레시피

const { LlamaEngine } = require('termux-llamacpp');

async function main() {
  const llm = new LlamaEngine({ modelPath: 'qwen2.5-0.5b.gguf', nGpuLayers: 99 });
  await llm.generateStream('양자 컴퓨팅을 쉽게 설명해줘:', (tok) => process.stdout.write(tok));
  console.log('\n');
}

main();

5. 하드웨어 장애 대응 및 자동 복구 프로토콜

발생 증상 (에러 로그) 근본 원인 (Root Cause) 엔지니어링 조치 프로토콜
VK_ERROR_DEVICE_LOST Mali Valhall 아키텍처 정수 나눗셈 보폭 0 절삭 무한 루프 발생. --enforce-medium-matmul 옵션으로 워크그룹 크기 128 커널을 강제 바인딩합니다.
VK_ERROR_UNKNOWN (-13) 스냅드래곤 Adreno JIT 컴파일러 레지스터 할당 한도 초과. 특수화 상수 mul_mat_vec_max_cols = 2로 고정하여 안전하게 실행합니다.
배터리 구동 시 지연시간 급증 안드로이드 OS의 배터리 세이버가 CPU 빅코어를 오프라인 전환함. 스레드 친화도(thread_affinity=[4,5,6,7])를 통해 고성능 빅코어에 프로세스를 고정합니다.
프로세스 종료 후 VRAM 미반납 비정상 종료로 인한 POSIX 공유 메모리 핸들 잔류. RAII 소멸자를 호출하거나 shm_unlink()를 통해 좀비 버퍼를 즉시 회수합니다.
