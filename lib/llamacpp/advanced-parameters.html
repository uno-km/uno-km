Advanced Parameters & Tuning

Kernel-level tuning, buffer pool sizing, and thread configuration

1. Device Backend & Acceleration Modes

CLI FlagSDK ParameterDefaultBehavior
--device vulkan device="vulkan" - Strict GPU shader acceleration mode with Fail-Fast protection (no CPU fallback).
--device auto device="auto" Recommended Intelligent 12-stage hardware probe with automatic CPU NEON fallback.
--device cpu device="cpu" - Bypasses Vulkan loader for 0ms direct pure-ARM64 NEON execution.
