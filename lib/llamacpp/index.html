소개 및 아키텍처 개요

사전 빌드된 Vulkan GGUF 런타임 및 정밀 양자화 온디바이스 LLM 고속 구동 엔진

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install termux-llamacpp

# Node.js 공식 패키지 매니저
npm install termux-llamacpp

기술적 당면 과제

안드로이드 기기에서 Llama.cpp를 직접 컴파일하려면 20분 이상의 Clang/Ninja 빌드 시간, 극심한 발열과 배터리 소모, 링커 충돌 및 지속적인 GGUF 포맷 버전 불일치가 발생합니다.

아키텍처 혁신 및 기술 돌파구

Qualcomm Adreno 및 ARM Mali GPU에 최적화된 Vulkan 컴퓨트 백엔드와 양자화 연산 엔진을 사전 빌드하여, 10초 만에 완벽히 설치되고 서브 50ms 지연시간으로 구동되는 LLM 환경을 제공합니다.

핵심 가치 제안 (Why It Matters)

설치하다 지쳐 포기했던 스마트폰 대화형 AI, 이제 10초 만에 끝납니다. 폰이 뜨거워지거나 꺼질까 봐 조마조마할 필요 없이, 가장 최신의 강력한 언어 모델과 언제 어디서나 자유롭게 대화하세요.

주요 기능 및 하드웨어 강화

사전 빌드된 무컴파일 바이너리 배포

Clang이나 Ninja 빌드 없이 pip 및 npm으로 사전 검증된 Android ARM64 네이티브 런타임을 즉시 설치합니다.

Vulkan GPU 레이어 100% 오프로드

트랜스포머 전 레이어를 모바일 GPU VRAM에 상주시켜 CPU 연산 병목을 제거하고 35.8 t/s의 초고속 추론을 지원합니다.

GGUF 최신 양자화 포맷 완벽 지원

Q4_K_M, Q5_K_M, Q8_0 등 최신 양자화 모델을 정밀도 손실 없이 지원합니다.

동적 컨텍스트 윈도우 관리

KV 캐시 순환 링 버퍼를 활용하여 긴 대화 도중에도 메모리 낭비 없이 안정적인 대화를 이어갑니다.

제로 셧다운 안전 메모리 보호

단말기 백그라운드 전환 시 안전하게 리소스를 보존하고 복원하는 모바일 보호 로직을 탑재했습니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
Vulkan GEMM/GEMV Shader SPIR-V 기반 고속 행렬 곱셈 셰이더, Adreno/Mali GPU 가속 하드웨어 가속
ARM NEON Q4_K Vector Core 128비트 SIMD 정수 행렬 연산, 배터리 절전 CPU 모드 프로덕션 안정
RoPE Frequency Calculation 온디바이스 회전 위치 임베딩 고속 삼각함수 연산 프로덕션 안정
FlashAttention Mobile Pipeline 메모리 대역폭 절감형 타일링 어텐션 커널 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from termux_llamacpp import LlamaEngine

# 1. 100% GPU 오프로딩 엔진 초기화
engine = LlamaEngine(
    model_path="~/.cache/termux-llamacpp/models/qwen2.5-0.5b-q4_k_m.gguf",
    n_gpu_layers=99,
    ctx_size=2048
)

# 2. 대화 스트리밍 생성
print("[질문]: 양자 컴퓨팅을 쉽게 설명해줘")
for token in engine.stream_chat("양자 컴퓨팅을 쉽게 설명해줘:"):
    print(token, end="", flush=True)
print()

Node.js (npm) 사용 예제

const { LlamaEngine } = require('termux-llamacpp');

async function main() {
  const llm = new LlamaEngine({ modelPath: 'qwen2.5-0.5b.gguf', nGpuLayers: 99 });
  await llm.generateStream('양자 컴퓨팅을 쉽게 설명해줘:', (tok) => process.stdout.write(tok));
  console.log('\n');
}

main();
