Official release records and technical milestones

v1.0.0 (2026-08-27) — Dual-Engine Multimodal Release

  • Dual-Engine Packaging: Full feature parity across Python (PyPI) and Node.js/TypeScript (npm).
  • Multimodal VLM Engine: On-device SmolVLM-500M and Qwen2-VL-2B inference with truthful metrics and OOM protection.
  • Vulkan Acceleration & Fallback: Auto Vulkan detection with graceful CPU fallback, and strict GPU isolated execution mode.
  • Classical Vision Filters: Pure Python/JS 5-stage Canny Edge, Sobel 3x3, Gaussian blur, and Haar Cascade face detection.
  • 1:1 termux-train Autograd Bridge: Direct extraction of ViT patch embeddings into termux-train tensors for edge LoRA fine-tuning.
  • 0-Point Baseline Granular Score: 100.0 / 100.0 (Grade A+ Perfect).
