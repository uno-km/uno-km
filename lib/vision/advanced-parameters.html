1. Unified 5-Backend CLI Standard Matrix

termux-vision strictly adheres to the uno-km ecosystem 5-backend standard (auto, gpu, vulkan, opencl, cpu):

Backend Choice Convenience Flag Target Microarchitecture Technical Mechanics
auto (Default)NoneAll Android SoCsProbes GPU Vulkan support; if available routes to Vulkan GPU, otherwise falls back to NEON CPU.
gpu / vulkan--gpuAdreno 830, Mali-G78/G68100% End-to-End Vulkan SPIR-V Compute shaders (3-pass VRAM pipeline barrier for CV, -ngl 99 for VLM).
opencl--openclQualcomm Adreno 600 (S20)Adreno OpenCL 2.0 kernel acceleration, avoiding SPIR-V float subnormal quirks.
cpu--cpu8-Core ARM64 (big.LITTLE)High-efficiency ARM64 NEON SIMD kernels without trigonometric atan2f; strict 0.00 MiB GPU VRAM.
