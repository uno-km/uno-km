The Engineering Challenge

Standard vision frameworks (OpenCV, TorchVision) suffer from massive binary sizes (>150MB), complex C++ compilation bottlenecks on ARM64 Termux, and lack seamless mobile VLM multimodal pipelines.

The Architectural Breakthrough

Provides 100% End-to-End Vulkan GPU Compute Canny Edge Detection (0.23ms), ultra-optimized ARM64 NEON C++ kernels (3.02ms), 5-stage classical filters, and on-device SmolVLM/Qwen2-VL Multimodal Vision-Language inference with Prebuilt-Asset-First idempotent installer.

Key Capabilities & Built-in Hardening

100% End-to-End Pure Vulkan GPU Compute Canny (0.23 ms)

Chains Sobel 3x3, NMS, and Hysteresis compute shaders entirely within VRAM using vkCmdPipelineBarrier, accelerating edge detection by 834x (0.23ms on Snapdragon 8 Elite Adreno 830).

Ultra-Fast ARM64 NEON C++ Kernel (3.02 ms)

Eliminates atan2f via tangent ratio bit quantization and 1-byte direction buffers, running Canny filtering in 3.02ms on Snapdragon 865 and 4.36ms on Exynos 1380.

Prebuilt-Asset-First Idempotent Installer (0.005s Skip)

Provisions verified precompiled ARM64 native binaries in 2 seconds from official releases, guaranteeing zero-build instant skip if assets already exist.

5-Backend Unified CLI Standard & Fail-Fast Gatekeeper

Enforces ['auto', 'gpu', 'vulkan', 'opencl', 'cpu'] across all subcommands; strictly rejects defective text-only binaries lacking --mmproj.

Canonical Usage Example

import termux_vision as tv

# 1. 100% Vulkan GPU Canny Edge Detection (0.23ms) or NEON CPU (3.02ms)
img = tv.io.load_image("photo.jpg")
edges = tv.cv.canny(tv.transforms.to_grayscale(img), low_threshold=40, high_threshold=120, backend="auto")
tv.io.save_image(edges, "edges.png")

# 2. On-Device VLM Multimodal Inference with 5-Backend Hardware Acceleration
with tv.vlm.load("smolvlm-500m", device="gpu") as engine:
    res = engine.describe("photo.jpg", prompt="Describe this scene in detail.", quality="optimal")
    print(f"Generated ({res.metrics.tokens_per_second:.1f} t/s via {res.metrics.backend}): {res.text}")

import tv from 'termux-vision';

// 1. Diagnostics & Hardware Probe
const doc = tv.doctor(true);
console.log(`Vulkan GPU: ${doc.vulkan.status} | RAM: ${doc.hardware.availableRamMb} MB`);

// 2. Multimodal VLM Inference with Quality Preset
const engine = await tv.load({ modelId: 'smolvlm-500m', device: 'gpu' });
const result = await engine.describe('photo.jpg', { quality: 'optimal', maxTokens: 150 });
console.log(`[${result.metrics.backend.toUpperCase()}] ${result.text}`);
engine.close();
