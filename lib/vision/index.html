소개 및 아키텍처 개요

순수 Canny/Sobel/Haar 알고리즘 및 SmolVLM Vulkan GPU 제로카피 온디바이스 컴퓨터 비전 SDK

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 파이썬 공식 패키지 매니저
pip install termux-vision

# Node.js 공식 패키지 매니저
npm install termux-vision

기술적 당면 과제

모바일 단말기에서 컴퓨터 비전 개발 시 150MB+ OpenCV와 거대 파이토치 빌드 병목이 발생하고, 카메라 프레임 전달 과정에서 메모리 다중 복사로 인해 발열과 심각한 프레임 드랍이 발생합니다.

아키텍처 혁신 및 기술 돌파구

외부 무거운 라이브러리를 완전히 배제한 순수 C/C++ 기반 Canny/Sobel/Haar 알고리즘과 SmolVLM Vulkan GPU 파이프라인을 구축하여, 제로카피 고속 이미지 인식과 시각 질의응답(VLM)을 실현했습니다.

핵심 가치 제안 (Why It Matters)

스마트폰 용량만 잡아먹는 무거운 프로그램 대신, 깃털처럼 가볍고 빠른 스마트폰 전용 인공지능 눈을 달아드립니다. 사진을 보고 상황을 이해하고 얼굴을 찾아내는 미래형 시각 능력을 내 폰에 선물하세요.

주요 기능 및 하드웨어 강화

순수 Canny/Sobel/Haar 0-의존성 코어

OpenCV 없이 순수 C/C++ 포인터 연산과 ARM NEON 정수 연산으로 초고속 픽셀 분석을 수행합니다.

SmolVLM Vulkan GPU 제로카피 파이프라인

카메라 버퍼를 CPU-GPU 간 중복 복사 없이 Vulkan 셰이더로 직접 공급하여 온디바이스 VLM 추론을 가속합니다.

카메라 프레임 직접 바인딩

Termux-Camera 연동 및 V4L2 네이티브 파이프라인을 지원하여 안드로이드 카메라 영상을 즉시 수신합니다.

결정론적 0-Drift 픽셀 정밀도

이기종 모바일 칩셋 간 부동소수점 오차 없이 비트 단위로 동일한 시각 분석 결과를 보장합니다.

메모리 누수 방지 RAII 생명주기

프레임 버퍼를 순환 풀로 재활용하여 장시간 비디오 스트림 분석 시에도 메모리 누수가 일절 발생하지 않습니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
Pixel Gradient Convolution ARM NEON 128비트 벡터 가속 3x3 소벨 및 가우시안 블러 프로덕션 안정
SmolVLM Multimodal Encoder Vulkan SPIR-V 이미지 패치 임베딩 및 어텐션 디코더 하드웨어 가속
Integral Image Cascade 정수 적분 영상 캐시 기반 실시간 얼굴 및 특징점 추적 프로덕션 안정
Zero-Copy Frame Ring Buffer POSIX shm 기반 프레임 인터리빙 및 렌더링 파이프 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

from termux_vision import VisionEngine

# 1. 제로카피 비전 엔진 초기화
engine = VisionEngine(mode="vlm", model_name="smolvlm-500m")

# 2. 이미지 분석 및 시각 언어 질의
print("[Vision] 이미지 분석 중...")
description = engine.ask_image("./samples/sample.jpg", "이 사진에 무엇이 있나요?")
print(f"[분석 답변]: {description}")

# 3. 고속 얼굴 탐지 수행
faces = engine.detect_faces("./samples/sample.jpg")
print(f"[검출된 얼굴 수]: {len(faces)}개 좌표: {faces}")

Node.js (npm) 사용 예제

const { VisionEngine } = require('termux-vision');

async function main() {
  const vision = new VisionEngine({ mode: 'detect' });
  const result = await vision.analyze('./samples/sample.jpg');
  console.log(`[탐지 결과]:`, result);
}

main();
