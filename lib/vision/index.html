Termux-Vision

Zero-Dependency On-Device Computer Vision & Multimodal VLM Inference Engine for Android Termux

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-vision
# or: npm install -g termux-vision
# or: bash <(curl -sSL https://raw.githubusercontent.com/uno-km/termux-vision/main/install.sh)

The Engineering Challenge

Standard vision frameworks (OpenCV, TorchVision) suffer from massive binary sizes (>150MB), complex C++ compilation bottlenecks on ARM64 Termux, and lack seamless mobile VLM multimodal pipelines.

The Architectural Breakthrough

Provides pure Python/JS 5-stage Canny Edge, Sobel 3x3, Gaussian Blur, 2D Integral Images, Haar Cascade Face Detection, and on-device SmolVLM/Qwen2-VL Multimodal Vision-Language inference with Vulkan GPU acceleration and automatic CPU fallback under 500MB RAM.

Key Capabilities & Built-in Hardening

Zero-Heavy C++ Dependency

Runs out-of-the-box on vanilla Termux Python (pip) and Node.js (npm) without complex OpenCV or node-gyp builds.

Multimodal VLM Inference Engine

Natively supports SmolVLM-500M and Qwen2-VL-2B models with truthful visual question answering and image description.

Vulkan GPU Acceleration & CPU Fallback

Auto-detects Vulkan GPU acceleration with graceful CPU retry on driver faults, or strict isolated GPU enforcement.

1:1 Native Bridge with termux-train

Seamlessly converts extracted vision feature maps and ViT patches directly into termux-train tensors for edge LoRA fine-tuning.

Supported Compute Kernels & Operations

Subsystem Category Operations & Kernels Status
Classical CV Filters 5-Stage Canny Edge Detector, Sobel 3x3, Gaussian Blur 5x5, 2D Integral Images, Morphology Production

Multimodal VLM SmolVLM-500M, Qwen2-VL-2B, Supervised llama-cli Bridge, Vulkan GPU Engine Production
Neural Vision Bridge ViT Patch Embeddings (16x16), MobileNet Feature Extractor, termux-train Auto-Grad Bridge Production
