Installation & Setup Guide

Hardware acceleration, Termux setup, and dependency management

Termux ARM64 Prerequisites

Run the following command in Termux to install native build tools and Vulkan drivers:

pkg update -y && pkg install -y python nodejs clang make cmake git termux-api wget vulkan-loader vulkan-headers vulkan-tools opencl-headers python-numpy libjpeg-turbo

1. Python Package Installation (PyPI)

pip install --upgrade pip setuptools wheel
pip install termux-vision

2. Prebuilt-Asset-First Native Engine Installation (Idempotent 0.005s)

# Fast provisioning of precompiled ARM64 native binaries (Vulkan CV & C++ engine)
termux-vision install

# Optional flags:
# termux-vision install --force        # Force redownload & reinstallation
# termux-vision install --from-source   # Force compilation from local C++ source
# termux-vision install --dry-run       # Audit installation status without writing

3. Direct GitHub Releases Wheel Asset

# Install official prebuilt v1.5.0 release wheel
pip install https://github.com/uno-km/termux-vision/releases/download/v1.5.0/termux_vision-1.5.0-py3-none-any.whl

4. Node.js CLI Installation (npm)

npm install -g termux-vision

5. Hardware GPU Acceleration Runtime (Full Suite)

pip install termux-vision ameva-runtime termux-llamacpp
termux-vision doctor

6. One-Line Bootstrap Installer

curl -sL https://raw.githubusercontent.com/uno-km/termux-vision/main/install.sh | bash
