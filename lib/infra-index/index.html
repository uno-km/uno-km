소개 및 아키텍처 개요

에지 인프라 실시간 관측성, 분산 하드웨어 텔레메트리 애그리게이터 및 노드 메시 인덱싱

1줄 빠른 설치 가이드

공식 패키지 매니저를 통해 즉시 단말기 환경에 설치하세요:

# 독립 네이티브 바이너리 설치 스크립트
curl -fsSL https://raw.githubusercontent.com/uno-km/infraindex-platform/main/install.sh | bash

기술적 당면 과제

분산된 모바일 및 에지 노드 클러스터를 감시할 때 기존 클라우드 모니터링 툴은 과도한 네트워크 대역폭과 시스템 자원을 낭비하여 스마트폰을 과열시키고 배터리를 방전시킵니다.

아키텍처 혁신 및 기술 돌파구

18MB 미만의 초경량 로컬 데몬과 암호화 상호 TLS(mTLS) 메시 합의 프로토콜을 통해 외부 데이터 유출 없이 초당 10만 건의 하드웨어 메트릭을 실시간 인덱싱합니다.

핵심 가치 제안 (Why It Matters)

복잡한 인프라 관리 도구들을 스마트폰과 소형 기기들을 위한 가벼운 데몬 하나로 압축하여 손쉽게 구동합니다.

주요 기능 및 하드웨어 강화

외부 유출 없는 100% 로컬 인프라 관측성

모든 하드웨어 메트릭이 로컬 네트워크 안에서만 처리되어 클라우드 유출을 방지합니다.

초경량 18MB 상주 메모리 풋프린트

스마트폰 시스템 자원을 거의 점유하지 않는 극소형 데몬으로 설계되었습니다.

상호 TLS(mTLS) 기반 노드 메시 보안

모든 피어 노드가 암호화 인증을 거쳐 안전하게 연결됩니다.

실시간 SoC 온도 및 배터리 감시

기기 과열 발생 시 자동으로 워크로드를 분산하거나 절전 모드로 전환합니다.

원클릭 분산 클러스터 자동 편성

새로운 단말기가 켜지면 토큰 인증을 통해 즉시 클러스터에 자동 편입됩니다.

지원 연산 커널 및 하드웨어 가속 매트릭스

서브시스템 분류 지원 연산 및 가속 커널 상태
Lightweight Mesh Consensus RAFT 기반 초경량 에지 노드 상태 합의 엔진 프로덕션 안정
Telemetry Metric Ring Buffer 메모리 상에서 실시간 롤링 메트릭을 유지하는 링 버퍼 프로덕션 안정
mTLS Dynamic Handshake 노드 간 종단간 암호화 보안 통신 터널 프로덕션 안정
Fault-Tolerant Failover Watchdog 노드 다운 시 1초 만에 감지하고 워크로드 재배치 프로덕션 안정

표준 사용 예제 (Python & Node.js)

Python (pip) 사용 예제

import urllib.request, json

# 1. 로컬 에지 인프라 데몬 상태 쿼리
req = urllib.request.Request("http://127.0.0.1:9090/v1/telemetry")
with urllib.request.urlopen(req) as resp:
    data = json.loads(resp.read().decode())
    print(f"[Infra-Index] 노드 ID: {data['node_id']} | CPU: {data['cpu_usage']}% | VRAM: {data['vram_usage']}MB")

Node.js (npm) 사용 예제

const http = require('http');

http.get('http://127.0.0.1:9090/v1/mesh/peers', (res) => {
  let raw = '';
  res.on('data', chunk => raw += chunk);
  res.on('end', () => {
    const peers = JSON.parse(raw);
    console.log(`[Infra-Index] 활성 메시 노드 수: ${peers.length}`);
  });
});
