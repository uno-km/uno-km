Platform Overview & Live Deployment

Infra-Index aggregates compute resource offerings from 69 global cloud service providers (CSPs) in real time. It monitors spot and on-demand pricing across 159+ GPU models, 23+ server CPUs, 90+ object storage tiers, and 220+ bare-metal configurations with bit-exact sub-second response times.

System Architecture & Topology

The platform is architected across three decoupled, high-availability tiers engineered for zero data drift and ultra-low latency:

Edge Presentation Tier

Next.js 16 App Router hosted on Vercel Global Edge CDN with Turbopack, TailwindCSS v4, React Query v5 optimistic caching, and Recharts financial candlestick charts.

Serverless ASGI Backend Tier

High-throughput FastAPI engine running on Python 3.12 with asyncpg connection pooling, 4-tier Upstash Redis memory cache fallback, and universal CORS routing.

Dual Neon Storage & Batch Tier

Serverless PostgreSQL clusters with composite B-Tree indexing on (model, provider, region, timestamp) and 153 isolated crawlers partitioned into DEV and PRD schedules.

Key Architectural Breakthroughs

4-Tier Upstash Redis Fallback

Ensures 100% cache hit reliability by gracefully cascading through environment-prefixed keys (infraindex:prod: → infraindex:dev: → root envelope keys) before touching disk.

Neon Composite B-Tree Indexing

Accelerates complex time-series queries over 32,000+ historical price records from 15.4 seconds down to 800 milliseconds during cold cache invalidation.

Dual-Tier Crawler Isolation

Isolates development testing from production data integrity through dedicated CLI run configurations (run_dev_crawl.ps1 vs run_prd_crawl.ps1).
