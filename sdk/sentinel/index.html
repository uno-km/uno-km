Privacy-First Security Observability Layer for Web Applications

"웹 서비스에 들어오는 트래픽을 관측하고, 측정하고, 설명하고, 점수화한다."

AMEVA Sentinel is a self-hosted, sovereign security observability layer that evaluates session automation risk in customer-owned infrastructure without transmitting raw user data to 3rd-party SaaS providers.

⚡ 3-Minute Quickstart

1. Backend / Edge Handler (1-Line Evaluation)

import { sentinel, SentinelAction } from '@ameva/sentinel';

export async function POST(req: Request) {
  const risk = await sentinel.score(req);

  if (risk.action === SentinelAction.RATE_LIMIT) {
    return new Response("Rate Limit Exceeded", { status: 429 });
  }

  if (risk.action === SentinelAction.REQUIRE_APP_VERIFICATION) {
    return new Response(JSON.stringify({ error: "2FA Required" }), { status: 401 });
  }

  // Proceed with standard business logic...
}

2. Frontend Client (React Hook)

import { useSentinel } from '@ameva/sentinel/react';

export default function LoginForm() {
  const { score, isSuspicious } = useSentinel();

  return (
    <form>
      {isSuspicious && <p className="warning">추가 인증이 필요합니다.</p>}
      <input type="text" placeholder="Username" />
      <input type="password" placeholder="Password" />
      <button type="submit">Login</button>
    </form>
  );
}

📜 Policy as Code

Security rules are versioned and reviewed natively via git diff:

import { createPolicy, rules } from '@ameva/sentinel';

export const loginPolicy = createPolicy({
  version: "2026-08-21.1",
  rules: [
    rules.webdriver({ weight: 20 }),
    rules.burst({ weight: 30, threshold: 50, windowMs: 10000 }),
    rules.suspiciousUA({ weight: 15 })
  ]
});
