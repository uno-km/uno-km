@ameva/forge · v1.0.0

Runtime:Browser WebGPU / Pyodide WASM
Core Ops:Autograd, Linear, Attention, SGD
Memory:WeakRef GC & Zero-Leak Pool

📱 Termux-Playwright

pip install · v1.61.2

PRoot나 Root 권한 없이 안드로이드 Termux 환경에서 정품 Chromium 헤드리스 브라우저 자동화를 실행하는 런타임 최적화 라이브러리.

Platform:Android Termux (aarch64 / x86_64)
Hardening:Bionic RPC, ProcessReaper, Stealth
Storage:RAM Cache & eMMC Flash Protection
📖 공식 문서 (GitHub Pages) 📦 PyPI 공식 패키지

⚙️ MCP-Wasm-Toolkit

WASM Core · v1.0.0

브라우저 WASM(Pyodide) 샌드박스로 위험 연산을 완전 격리하고, SSE(ntfy) 채널을 통해 도구를 3초 내 핫리로드하는 동적 툴킷 허브.

Security:100% Client-Side Sandbox Isolation
Sync:SSE Real-time Dynamic Hot-Reload
Bridge:Local Port 9000 WebSocket Proxy
📖 공식 문서 (GitHub Pages)

🧠 BitNet Engine

ARM / Exynos Scalar · v1.0.0

1-bit 양자화 모델(1.58-bit LLM)을 엣지 디바이스 및 저전력 CPU에서 극한의 전력 효율로 구동하는 초경량 추론 프레임워크.

Quantization:1.58-bit Ternary Weights {-1, 0, 1}
Hardware:ARM Neon / Exynos Scalar Fallback
Efficiency:Ultra-Low mW Power Footprint
