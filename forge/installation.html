Installation & Setup Guide

Hardware dependencies, WebGPU flags, and package installation

Hardware Acceleration Requirements

AMEVA-Forge requires a WebGPU-enabled runtime (Chromium 113+, Safari 18+, Edge 113+, or Node.js with @webgpu/wgpu). No native CUDA compilation or cloud GPUs required.

1. Python Package Installation (PyPI)

Install the official AMEVA-Forge Python package into your local or virtual environment:

pip install ameva

2. Browser CDN & Standalone ESM Import

Embed the hardware WebGPU compute engine directly into your web applications with zero build steps:

<!-- IIFE Standalone Bundle -->
<script src="https://uno-km.github.io/uno-km/lib/forge/dist/index.iife.js"></script>

<!-- Or Modern ES Module -->
<script type="module">
  import { Tensor, nn, optim } from 'https://uno-km.github.io/uno-km/lib/forge/dist/index.esm.js';
  
  // Initialize GPU Device Context
  const x = new Tensor([1.0, 2.0, 3.0, 4.0], { requiresGrad: true, device: 'gpu' });
  console.log('WebGPU Tensor Allocated:', x);
</script>

3. Browser WebGPU Feature Verification

Verify that your browser environment supports native WebGPU compute shaders:

if (!navigator.gpu) {
  console.error("WebGPU is not supported on this browser. Please enable 'chrome://flags/#enable-unsafe-webgpu' or use Chrome 113+.");
} else {
  const adapter = await navigator.gpu.requestAdapter();
  const device = await adapter.requestDevice();
  console.log("WebGPU Hardware Adapter Active:", adapter.info);
}

4. Node.js Native Backend Execution

For headless CI/CD and server environments without display servers:

npm install ameva-forge
# or run in headless WebGPU runtime
node --enable-source-maps index.js
