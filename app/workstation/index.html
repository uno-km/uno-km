🏢 AMEVA Workstation Web

The sovereign, zero-subscription personal AI workstation engineered to run entirely inside your browser using client-side WebGPU acceleration. No cloud API keys, no server costs, and 100% absolute privacy.

🚀 Launch Live Workstation Web 🐙 GitHub Repository

1. 100% On-Device WebGPU Local AI

Empowered by WebGPU compute shaders and WebLLM execution, AMEVA Workstation runs state-of-the-art quantized LLMs (Qwen2.5 0.5B, 1.5B, and 7B) directly against your device's native GPU hardware.

  • Zero API Costs: No monthly OpenAI/Claude subscriptions or token rate limits.
  • Instant Offline Readiness: Model weights cache in browser IndexedDB for instant offline execution.

2. 3-Second MapReduce PDF & Document Intelligence

Upload large PDF, DOCX, or text documents and receive hierarchical MapReduce summaries and semantic extraction in under 3 seconds using client-side vector search and chunked parallel workers.

3. Built-in High-Performance Media Suite

  • 1-Second AI Background Removal: Instant subject segmentation powered by in-browser WASM neural networks.
  • In-App Video Trimmer & Cutter: Zero-upload client-side video clipping with FFmpeg WASM.
  • Automated Silence Removal: Intelligent audio waveform thresholding for fast content creation.

4. Absolute Enterprise Security & Data Sovereignty

No document, audio sample, or user prompt is ever transmitted to an external server. Everything executes inside the client-side sandboxed browser runtime, making it compliant with the strictest enterprise data protection regulations.
