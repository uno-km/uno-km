⚡ Simple & Direct Maintainership

AMEVA는 복잡한 투표 정족수나 거창한 이사회 같은 형식적인 모래주머니를 차지 않습니다. 창립자 @uno-km이 직접 소스코드를 리뷰하고 머지하며, 실기기에서 검증된 진짜 성능 지표만을 기준으로 소통합니다.

1. 의사결정 원칙 (Decision Making)

정치나 직급이 아닌, 실제 스마트폰 단말기에서 계측된 벤치마크 지표가 모든 기술적 결정의 기준입니다. 코드가 가볍고 빠르며 버그가 없다면 그 어떤 제안이라도 적극 수용합니다.

2. 피드백과 참여 방법 (How to Contribute)

  • GitHub Issues: 버그, 크래시, 개선 아이디어가 있다면 주저 없이 이슈를 등록해 주세요. 쓴소리도 언제나 달게 받습니다.
  • Pull Requests: 더 빠른 커널, 메모리 절약 알고리즘, 문서 개선 PR을 언제나 환영합니다.
  • GitHub Star(⭐️): 프로젝트가 마음에 드셨다면 깃허브 스타를 꼭 눌러주세요. 1인 개발자에게 가장 큰 힘이 됩니다.
  • 상업적 협업 문의: 비즈니스 연동이나 기술 문의는 이메일(zhfldk014745@naver.com)로 편하게 연락 주시면 감사하겠습니다.
