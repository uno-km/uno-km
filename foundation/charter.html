🌱 A Clean, Honest & Direct Charter

AMEVA는 화려한 관료주의나 형식적인 재단 허세를 지양합니다. 개발자 @uno-km이 직접 밤낮으로 코드를 깎아 만든 1인 인디 온디바이스 AI 프로젝트이며, 누구나 스마트폰과 구형 기기에서 무료로 로컬 지능을 실행할 수 있도록 하는 것이 유일한 목표입니다.

1. 프로젝트 설립 취지 (Mission)

빅테크 클라우드 벤더의 비싼 API 토큰 과금에 종속되지 않고, 우리가 이미 주머니에 소유하고 있는 스마트폰과 서랍 속 구형 기기로 100% 자립 구동하는 온디바이스 AI 생태계를 만듭니다.

2. 지적재산권 및 소스코드 안내 (Code Ownership)

  • My Code, My Craft: 이 저장소의 모든 C++20 커널, Vulkan 셰이더, 라이브러리 코드는 제 손으로 직접 깎아 만든 소중한 자산입니다.
  • 자유로운 학습과 오픈소스: 비영리, 개인 연구, 학습 목적에는 언제든 자유롭게 사용하실 수 있습니다.
  • 무단 도용 및 복제 경고: 출처 표기 없는 무단 복제나 상업적 표절 시에는 DMCA 테이크다운을 포함하여 매우 안타까운 일이 발생할 수 있습니다.
  • 상업적 제휴 및 문의: 상업적 도입이나 비즈니스 연동이 필요하신 경우 먼저 이메일(zhfldk014745@naver.com)로 편하게 연락 주시면 감사하겠습니다.

3. 참여와 협업: 함께 토론하고 발전해 나갑시다

복잡한 위원회나 투표 절차 같은 모래주머니는 없습니다. 프로젝트가 마음에 드셨다면 GitHub Star(⭐️) 한 번 꾹 눌러주시고, 코드에 부족한 점이 있다면 언제든 GitHub Issues와 PR로 회초리를 들어주십시오. 함께 치열하게 토론하며 더 가볍고 빠른 코드로 발전시켜 나가겠습니다.
