Termux-Vision

Zero-Dependency On-Device Computer Vision & Multimodal VLM Inference Engine for Android Termux

1-Line Quick Installation

Install the official package directly into your runtime:

pip install ameva-core
# or: npm install @ameva/core

The Engineering Challenge

Standard vision frameworks like OpenCV, TorchVision, and heavy Python runtimes fail or crash on mobile Termux due to multi-gigabyte library sizes, missing GLIBC bindings, and severe thermal throttling.

The Architectural Breakthrough

Eliminates heavy C++ dependencies by compiling SIMD NEON vision kernels directly with zero-copy image transforms, delivering real-time object detection, segmentation, and VLM multimodal inference under 150MB RAM.

Key Capabilities & Built-in Hardening

Zero-Dependency Native Runtime

Operates with zero heavy OpenCV/PyTorch bloat, running directly on Android Bionic libc.

ARM64 NEON Vectorized Image Kernels

Hand-vectorized RGB/BGR resizing, normalization, and NMS kernels.

On-Device VLM Multimodal Support

Integrated lightweight visual language model pipeline for edge visual question answering.

Supported Compute Kernels & Operations

Subsystem Category Operations & Kernels Status
Pre-processing Bilinear Resize, RGB2BGR, Float Normalization (NEON) Production
Inference Engine NanoDet-Plus, MobileSAM, Fast-VLM GGUF Production
Post-processing Fast-NMS Vectorized, Soft-NMS, Box Decoder Production

Canonical Usage Example

import termux_vision as vision

# 1. Load zero-dependency mobile vision engine
engine = vision.VisionEngine(model="nanodet-plus-arm64")

# 2. Run real-time detection on mobile image
results = engine.detect("sample.jpg", conf_threshold=0.45)
for obj in results:
    print(f"Detected: {obj.label} ({obj.score:.2f}) at {obj.bbox}")

import { VisionEngine } from 'termux-vision';

const engine = new VisionEngine({ model: 'nanodet-plus-arm64' });
const detections = await engine.detect('sample.jpg', { confThreshold: 0.45 });
console.log(detections);
