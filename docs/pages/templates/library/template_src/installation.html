Installation Guide

Step-by-step setup instructions across diverse package managers and hardware backends.

Python Package (PyPI)

Install via pip directly into your virtual environment:

pip install {{package_name_pypi}}

NPM Package

Install via npm or yarn for web/Node environments:

npm install {{package_name_npm}}

Cargo Crate

Add dependency to Cargo.toml:

[dependencies]
{{package_name_pypi}} = "{{version}}"

Build from Source

git clone {{github_repo_url}}.git
cd {{package_name_pypi}}
pip install -e .
